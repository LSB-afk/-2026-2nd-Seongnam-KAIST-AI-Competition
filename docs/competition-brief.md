# 성남 타임스토리 — 공모전 제안 요약

작성일: 2026-09-14 · 제출용 1쪽 내용 초안. 공식 양식·세부 주제·배점은 확인 전이며, 아래 문제와 도입 조건은 검증할 가설이다.

**제안:** 성남 문화홍보 담당자가 공식 자료에 근거한 카드뉴스를 만들고, AI가 발견한 문제와 수정 이유를 검토할 수 있는 제작 도구를 제안한다.

| 항목 | 제안 내용과 근거 상태 |
| --- | --- |
| 지역 문제 가설 | 지역문화 홍보물 제작에서 자료 탐색·독자에 맞는 재작성·사실 검토가 반복되어 담당자 부담이 크다. 담당자 인터뷰와 업무 측정은 아직 없다. |
| 사용자 / 수혜자 | 우선 사용자는 성남 문화시설·지역기관의 문화홍보 담당자. 수혜자는 지역문화 정보를 접하는 시민이며 첫 독자로 청소년을 검토한다. |
| 기존 작업 | 공식 자료 수집 → 초안 작성 → 사실·표현 검토 → 승인·전달. 단계별 실제 도구와 병목은 최근 제작 사례로 확인한다. |
| 현재 서비스 | 등록 장소 8곳과 세 제작 목적을 선택해 사진이 포함된 카드 4장·대본·출처·검수 이력을 만든다. 지도는 자료 선택, 타미는 사용 안내를 맡는다. |
| 핵심 AI | 공식 원문 탐색 → 문구 작성 → 원자 주장별 지지·충돌·불충분 검사 → 필요한 근거 재탐색 또는 문제 문구 수정 → 재검수. 미해결·반복·상한 도달은 담당자 검토로 넘긴다. |
| 사람의 역할 | 원문과 수정 전후를 확인하고 문구·사진을 편집한다. 최신 버전의 검수 후 승인하며, 실제 기관 게시 절차는 별도다. |
| 산출물 | 1080×1080 PNG 4장, 장별 문구·대본, 근거·출처 JSON, 검수·수정 이력과 ZIP. 마지막 장의 미래 문구는 상상으로 표시한다. |
| 측정할 효과 | 현재 업무 대비 승인 가능한 결과까지의 시간, 담당자 수정 수, 사람이 판정한 미지원 사실 수/전체 사실 수, 승인 여부, API 추정 비용. 개선 수치는 아직 없다. |

**보여줄 전후 사례:** 판교박물관 카드에 의도적으로 넣은 역사적 계승 문장을 검수하고, 근거를 재확인해 수정·재검수하는 기록을 제시한다. 주입 오류와 실제 모델의 자연 발생 오류를 구분한다. 현재 fixture는 준비된 응답의 실행 시연으로, 실제 AI의 판단 성능 증거가 아니다.

**확보한 것과 남은 것:** 장소별 제작·검수·편집·승인·파일 전달과 회귀 검증 기록은 저장소에 있다. 실제 텍스트·이미지 모델 연결 검증, 사람 검토를 마친 평가 정답, 담당자 인터뷰와 업무 비교 결과는 아직 없다. 최신 실행 근거는 [평가 기록](evaluation.md)을 인용한다. 자동화 테스트 통과 수를 정확도·수요·업무 개선 수치로 바꾸어 쓰지 않는다.

**현장 적용 가정:** 한 기관의 로컬 초안 제작에서 시작해 기존 게시 절차로 넘긴다. 운영자, 자료 갱신자, 승인자, 월 제작량, 호출 비용 예산, 오류 정정 담당자를 기관과 정해야 한다. 도입 합의는 없고 기관 인증·공개 게시 기능도 현재 범위 밖이다. 시민의 이해·참여 효과는 별도 독자 평가가 필요하다.

**다음 증거:** 최근 홍보물 중심 담당자 탐색 인터뷰 → 사람의 공식 원문 대조 → 설정·예산 확보 후 실제 AI 기술 비교 → 담당자의 기존 업무와 서비스 사용 짝 비교. 반박 사례·실패·추가 검토 부담도 공개한다. [현장 검증 질문지와 빈 기록](field-validation.md), [평가 CSV](templates/field-workflow-pairs.csv), [3분 연습 대본](demo.md)을 준비했다. 3분은 연습 시간이며 공식 발표 시간은 미확인이다.
