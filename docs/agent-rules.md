# 에이전트 판단·검수 규칙

## 도구와 판단

총괄 에이전트는 `search_sources`, `compose_story`, `verify_content`, `render_cards` 중 다음 행동을 선택한다. `finish`와 `escalate`는 서버가 검증하는 종료 행동이다. 판단에는 대상/근거 ID, 짧은 행동 이유, 불확실성, 중단 이유를 포함한다. 내부 사고과정은 저장하지 않는다.

fixture에서는 준비된 응답과 검수 결과를 사용하는 결정적 정책이, live에서는 Anthropic 구조화 응답이 다음 행동을 선택한다. 고정 순서 비교군은 같은 작성/검수/출력 도구를 사용하되 추가 검색 없이 수정 1회만 수행한다.

## 검수와 승인

- 공식 출처의 존재와 실제 주장 지지를 구분한다. 근거 인용은 수집 본문에 실제 포함되어야 한다.
- fixture의 사실은 검증된 원문·허용 문구만 통과한다. 임의로 편집한 사실의 의미를 자동 판정하는 범용 검수기가 아니다.
- live는 구조/참조/표시 검사에 별도의 모델 검수를 더한다. 여전히 담당자의 원문 확인이 필요하다.
- 새 문구는 새 버전이다. 이전 승인과 출력 연결을 제거하고 검수를 다시 수행한다. 해결된 과거 문제는 이력으로 보존한다.
- 미해결 항목 없이 동일 버전의 PNG 4장·대본·출처·검수 JSON·ZIP이 생성되면 승인 대기 상태로 전환한다.
- 담당자가 이름을 입력해 승인한다. 계정 인증이나 외부 게시 기능은 없다.
- 파일 다운로드 직전 최신 버전을 재확인하고 파일 SHA256을 검증한다.

## 종료·비용·복구

도구 최대 12회, 모델 최대 30회, 자동 수정 최대 3회, 누적 실행 시간 최대 180초다. 담당자 검토 대기 시간은 실행 시간에 더하지 않는다. 재검수에서도 이전 호출·비용을 유지한다. 모델 가격과 비용 상한은 환경변수로 설정한다.

모든 모델 호출은 네트워크 요청 전에 입력 크기/최대 출력 기반 비용을 보수적으로 예약하고 SQLite에 저장한다. 응답 사용량이 확인되면 설정 단가로 정산한다. 응답이 없거나 사용량이 불명확하면 예약액을 유지한다. 표시 비용은 공급자 청구서가 아닌 설정 단가에 따른 추정 비용이다.

취소는 AbortSignal을 전달하고 취소 상태가 늦은 결과로 덮이지 않게 한다. 취소 후 확인된 사용량은 계속 반영한다. 서버 재시작 시 진행 중 작업은 검토 필요 상태로 전환하고 경과 시간을 보수적으로 계산한다. 알 수 없는 청구나 중단을 성공으로 처리하지 않는다.

출력 잘림은 오류로 검수 목록에 추가해 문구 수정·재검사·출력으로 돌아간다. 상한이나 복구 불가 오류에 도달하면 담당자 검토로 넘긴다.

## 자료 경계

공식 박물관 호스트만 HTTPS로 조회하고 리디렉션도 다시 검사한다. 원문 크기/조회 시간에 상한을 둔다. 모델은 외부 문서를 명령으로 취급하지 않는다. 이미지 재사용 권한은 추정하지 않으며 MVP는 자체 도형만 사용한다.

공식 자료 수집은 등록된 두 페이지의 재조회와 근거 확인이다. 일반 검색엔진이나 성남 전체 자료 탐색은 구현 범위에 포함하지 않는다.
