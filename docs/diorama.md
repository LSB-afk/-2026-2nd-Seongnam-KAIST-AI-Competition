# 성남 3D 여행

주 메뉴의 독립 화면이다. `/?view=diorama`로 열며 기존 장소 탐색의 목록·지도 선택과 별개로 복원된다.

3D 지도는 브라우저 화면 전체를 채운다. 왼쪽 위에는 주 메뉴·지역 선택, 오른쪽에는 접을 수 있는 명소 정보, 아래에는 자동 감상 조작이 놓인다. ‘감상 설정’으로 속도·감상 시간·이름표 등을 설정한다. 모바일에서는 명소 정보가 접힌 하단 패널로 시작하며 명소와 설정 중 하나씩 펼쳐 쓴다. 패널 안의 긴 내용만 스크롤하고 빈 지도 영역은 바로 조작할 수 있다. Escape로 패널을 닫으면 해당 열기 버튼으로 키보드 초점이 돌아간다.

## 사용

1. 처음 열면 성남 전체가 보인다. 수정구·중원구·분당구를 선택하면 같은 도시 안에서 해당 지역으로 이동한다.
2. 기본 ‘이동’ 모드에서 마우스 왼쪽 드래그·한 손가락으로 지도를 끈다. 이름표 위에서도 끌 수 있고, 이름표나 명소 표지 이외의 지점을 클릭하면 확대와 각도를 유지한 채 그곳을 화면 중심으로 옮긴다. 휠은 마우스 위치를 기준으로 확대하고 두 손가락은 확대와 이동을 함께 한다. ‘회전’ 모드나 오른쪽 드래그로 각도를 바꾸고 ‘위에서 보기’로 북쪽이 위인 시점을 얻는다. 캔버스에 초점을 맞추면 방향키는 현재 모드의 이동·회전, Shift+방향키는 회전, +/−는 확대·축소, Home은 선택한 장소 시점 복원이다.
3. 이름표나 검색 목록에서 52개 명소를 고른다. 이름·종류·지역 검색과 8개 단위 페이지 이동을 지원한다. 선택하면 목록이 접혀 정보·제작 버튼을 바로 읽을 수 있고 키보드 초점은 목록 펼치기 버튼으로 이어진다. ‘조금 더 가까이’는 관찰 지점으로, ‘성남 전체’는 도시 전체 구도로 이동한다.
4. 자동 감상은 현재 장소의 첫 관찰 지점에서 시작한다. 도시·지역 보기에서는 첫 감상 대상부터 시작한다. 52개 장소의 55개 관찰 지점을 지원하며 이동 속도와 설명 감상 시간은 별도 설정이다. 일시정지·다음·재개·종료와 반복 감상, 저장한 장소만 감상을 지원한다.
5. 등록된 사진·공식 안내·위치 지도로 확인하고 ‘이 장소로 카드뉴스 만들기’를 누르면 기존 작업실에 같은 장소가 입력된다. 신규 44곳은 사진·운영시간·휴무·요금이 미확인이므로 `null`이다. 등록 사진이 없어도 글 중심 카드 4장을 만들며 이후 사용 권한이 있는 사진을 추가할 수 있다. 타미도 현재 3D 장소에 맞춰 안내한다.
6. ‘가게·도로’는 이름 있는 OSM 장소 3,177곳과 도로명 1,627개를 별도로 검색한다. 선택한 명소·지역에 가까운 결과를 최대 20개 표시하고 등록된 주소·분류·OSM 원본 링크를 제공한다. 선택하면 실제 대표 좌표로 확대하지만 관광명소나 카드뉴스 제작 대상을 바꾸지 않는다. 근접 지도에는 가게 이름표를 최대 24개 표시한다.
7. 감상 설정에서 사람·자동차·움직임을 켜고 끈다. 도시 활기는 0.5 / 1 / 2배, 사람 크기는 1 / 1.7 / 2.5배다. 기본은 사람 3,600명·자동차 1,500대와 크기 1.7배이며 최대 밀도는 7,200명·3,000대다. 실제 인구나 실시간 교통량이 아니다.

재생은 새로고침 후 자동 시작하지 않는다. 장소 탭 변경, 화면 이탈, 탭 숨김, 직접 카메라 조작은 자동 감상을 중단한다. 이름표 선택은 재생 중에도 해당 지점으로 이동한다. 기기의 모션 줄이기 설정은 카메라 보간·자동 회전·사람과 자동차 이동보다 우선한다. 설정 저장 실패는 현재 이용을 막지 않는다.

## 도시 이야기·시간·기억

명소 패널의 ‘내 이야기’는 2~3곳을 모아 한 번의 카드 제작으로 연결한다. 장소마다 사진 사용 여부·등록된 공식 자료·500자 이내 메모·현재 카메라 구도를 저장하고 순서를 바꿀 수 있다. 카드는 네 장이며 첫 세 장이 모든 선택 장소를 다루고 마지막은 상상이다. 공식 근거·카드·사진에 장소 식별자를 묶어 같은 공식 페이지의 다른 장소 설명이 섞이지 않게 검증한다. 사진 제외 선택은 최초 이미지에 적용하며 이후 사용자가 명시적으로 사진을 추가할 수 있다.

작업실의 ‘카드와 3D 장면 함께 보기’로 지도를 재생한다. 자동 재생은 명시적으로 시작하며 직접 조작·화면 숨김·모션 줄이기 설정에 따라 멈춘다. 저장한 구도가 없으면 장소의 기본 구도를 사용한다. 점선은 이야기 순서이며 실제 이동 경로가 아니다.

공유본은 현재 검수와 담당자 승인이 끝난 버전만 만든다. `/stories/{id}` 전용 화면은 작업실과 제작 기록을 불러오지 않는다. 서버에는 카드·해당 장소·출처·이미지 크롭·카메라만 투영한 불변 스냅샷을 저장하며 원본 작업을 수정해도 기존 공유본은 유지된다. 초안 메모·승인 담당자·내부 작업 식별자는 공개 데이터에서 제외한다. QR은 외부 서비스 없이 생성하고 긴 주소는 링크 공유로 안내한다. 로컬 주소는 다른 기기에서 접속할 수 없으며 앱의 작성 API는 외부 공개 운영용 인증을 제공하지 않는다.

‘시간·탐정’의 시간 렌즈는 판교박물관의 날짜가 있는 공식 기록과 등록 사진의 촬영 정보를 구분한다. 현재 지도 기준일과 사진 촬영일도 별도로 표시한다. 기록이 없으면 없다고 안내하고, ‘만약’의 아이디어는 상상 제작 입력으로 전달한다. 타미 탐정단은 판교박물관·중앙공원·모란민속5일장·율동공원·봉국사에서 공식 근거를 고르는 문제를 제공한다. 확인한 근거만 원문 링크와 함께 보고서에 담는다.

‘기억’은 장소별 비공개 기억과 최대 2MB 사진을 이 브라우저에 저장한다. 사진은 디코딩 후 최대 1024px로 다시 저장해 메타데이터를 제거한다. 권리·활용 동의와 이 기기의 명시적인 검토를 마쳐야 이야기 메모로 사용할 수 있다. 개인 기억이라는 표시를 붙이며 사진은 자동 전송하지 않는다. 활용 철회는 사진과 재사용 자격을 제거하고 기록을 삭제할 수도 있다. 중앙 서버의 시민 게시판·관리자 심사·다른 시민과의 동기화는 제공하지 않는다. 이야기 보관함이 손상되면 원본을 보존하고 내려받기와 명시적인 교체를 제공한다.

## 알아볼 수 있는 명소와 먹거리

기존 8곳은 실제 등록 사진을 이름표에 표시하고 사진이 없는 44곳은 공원·박물관 등 유형 아이콘을 쓴다. 이름표는 실제 장소 좌표에 붙으며 건물의 외관을 실측 복원한 것은 아니다.

‘먹거리’는 선정·소개 근거가 있는 8곳과 일반 OSM 음식점을 구분한다. 성남시 2026 힙스토어 4곳, 한국관광공사 소개 3곳, 블루리본 Pick 1곳을 수록했다. 정확한 좌표를 확인한 능라도본점·평양면옥·감미옥 본점만 지도 표지와 직선거리 3km 검색에 포함한다. 나머지 5곳은 ‘성남 전체’에서 출처와 확인한 주소 범위만 제공한다. 현재 인기·영업·대기 시간은 측정하지 않는다. [선정과 좌표·시간 기록 근거](city-story-sources.md)

## 표현의 범위

OSM 원본 도로 중심선과 건물 외곽선을 성남시 안에서 사용하며, 공원·숲·잔디·수면 등 토지 피복 영역 933개를 함께 표시한다. 임의 격자 도로·배경 건물과 기존 명소별 상징 건축물은 현재 도시에서 제거했다. 52개 명소는 확인된 좌표의 위치 표지로 연결한다. 신규 44곳의 실재 장소·소개 근거는 공식 자료로 확인했고 좌표는 공식 약도·관광공사·OSM 등 출처와 대표 지점의 한계를 별도로 기록했다.

| 자료 | 이번 스냅샷 | 현재 지상 표시 |
| --- | ---: | ---: |
| 도로 | 원본 way 15,100개 → 경계에서 자른 선 조각 15,222개 | 14,577개 조각; 터널·지하 645개 제외 |
| 건물 | OSM 객체 32,300개 | 32,299개; 지하 객체 1개 제외 |
| 이름 있는 장소 / 도로명 색인 | 3,177곳 / 1,627개 | 검색 가능; 장소별 영업 상태 미확인 |
| 토지 피복 | 영역 933개, 폴리곤 934개 | 원본 외곽선과 내부 구멍 유지 |

수평 10단위는 약 1km이고 동쪽은 +X, 북쪽은 −Z다. 건물 높이는 등록된 `height`를 우선하고, 없으면 층수×3m, 둘 다 없으면 9m를 사용한다. 도로 폭은 등록 폭·차로 수 또는 종류별 기본값을 쓰며 교량 높이도 `bridge`·`layer`를 바탕으로 추정한다. 지형은 평면이고 탄천은 기존 중심선에 폭 40m를 적용한 표현이다. 수면 자료에서 시 경계를 가로지르는 탄천 전체 면은 제외됐으므로 실제 강폭을 복원한 것으로 읽으면 안 된다.

OSM 미등록 건물·점포·면적이 있고 높이·폭·외관도 완전하지 않다. 사람과 자동차는 등록된 이동 가능한 도로를 따라 움직이는 연출이며 현재 혼잡도·영업 여부·길찾기 결과를 뜻하지 않는다. [도시 지리 출처·제외 내역](seongnam-urban-sources.md), [기존 구 경계·탄천 자료](seongnam-city-sources.md), [명소 확장 근거](seongnam-tourism-expansion-sources.md), [모형 자산 기록](diorama-assets.md)을 참고한다.

선택 장소의 실제 위치 지도는 같은 장소 데이터의 위경도를 사용하는 OpenStreetMap 공식 임베드의 단일 핀이다. 자동 감상 순서는 실제 이동 경로를 뜻하지 않는다. WebGL이 실패해도 장소 정보·등록된 사진·공식 링크·카드뉴스 제작의 대상은 같은 장소로 유지된다. 외부 지도·공식 페이지의 실제 로딩은 네트워크 상태에 의존한다. 도시 전체 보기에는 특정 장소의 제작 버튼을 표시하지 않으며 장소를 선택한 뒤 기존 제작 흐름으로 연결한다. ‘3D 화면 다시 불러오기’로 새 렌더러를 만들 수 있다.

지도 제스처는 설치된 Three MapControls를 사용한다. 왼쪽 드래그는 지면 교점을 기준으로 이동하고 놓은 뒤 관성을 적용하지 않는다. HTML 이름표와 캔버스가 같은 입력 영역을 공유하며, 드래그·두 손가락·취소를 단순 클릭과 구분한다. 구 받침면은 위치 이동용 바닥으로 취급하고 구 선택은 이름표·상단 버튼으로 유지한다. 이동·회전 전환은 카메라와 도시를 다시 생성하지 않는다.

페이지와 Three 렌더러를 두 단계로 지연 로딩한다. 대시보드에서는 WebGL을 생성하지 않으며 3D 화면 진입 때 전체 도시를 한 번 만들고 지역/명소 선택에는 카메라와 이름표만 갱신한다. 정적 구조물의 그림자는 초기 생성 때 갱신하고 움직이는 사람·자동차는 그림자를 만들지 않아 숨김/이동 후 잔상이 남지 않는다. 렌더러·카메라·모형·DOM 이름표는 프레임 루프가 관리하고 React는 250ms 간격의 감상 시간만 갱신한다.

렌더러는 `stopId/requestId`를 되돌려 최신 요청만 진행한다. 준비 완료 → 카메라 이동 완료 → 설명 감상 순서이며, 일시정지 중 다음 지점 선택 후 같은 요청으로 재개하는 경우에도 준비 완료를 다시 전달한다. 오류·재시도·언마운트 시 루프, 이벤트, 관찰자, 모델 기하·재질, 그림자 맵과 렌더러를 해제한다.
