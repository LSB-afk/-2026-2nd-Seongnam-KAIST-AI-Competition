# 3분 시연 대본

## 준비

`npm ci`, `npx playwright install chromium`, `npm run dev` 후 http://127.0.0.1:3000 을 연다. API 키 없이 실행하는 ‘데모’ 모드를 사용한다. ‘시연·비교 설정’은 에이전트 / 근거 없는 역사적 연결을 선택한다.

## 0:00–0:30 — 요청

“성남 문화홍보 담당자가 청소년용 카드뉴스 4장을 요청합니다. 마지막 장은 미래 문화공간을 상상하는 내용입니다. 오늘은 저장된 응답을 쓰는 재현 가능한 시연이며, 실제 모델 성능 평가는 별도로 진행합니다.”

‘카드뉴스 제작하기’를 누른다.

## 0:30–1:15 — 발견과 복구

“의도적으로 근거 없는 역사적 연결을 초안에 넣었습니다. 검수에서 발견하면 공식 자료를 추가 확인하고, 확인 가능한 설명으로 바꾼 뒤 다시 검사합니다.”

‘제작 기록’을 열어 검수 → 공식 원문 재확인 → 수정 → 재검수를 보여준다. 세 번째 카드를 선택하고 ‘수정 내역’에서 ‘판교 AI 산업으로 이어졌다’와 발굴조사 설명을 비교한다.

## 1:15–2:00 — 근거와 창작 구분

첫 번째 카드의 ‘문장 근거’에서 개관일 원문과 공식 출처를 연다. 네 번째 카드의 ‘상상 장면’ 표시를 보여준다.

“공식 출처가 있다는 사실만으로 문장이 맞는 것은 아닙니다. 문장과 원문이 연결되는지 확인합니다. 미래 장면은 실제 사업으로 오해되지 않게 표시합니다.”

## 2:00–2:40 — 승인과 전달

담당자 이름을 입력하고 ‘최종 결과 승인’을 누른다. 패키지 ZIP을 내려받아 카드 4장, 대본, 출처, 검수 내역을 보여준다.

“자동 검수 통과와 담당자 승인을 나눴습니다. 내용을 수정하면 버전이 바뀌고 이전 승인은 해제됩니다.”

시간이 남으면 세 번째 카드 제목을 수정하고 ‘수정 내용 재검수’를 누른다.

## 2:40–3:00 — 한계와 다음 실험

“자료를 확보하지 못하거나 반복 상한에 도달하면 근거 없이 완성하지 않고 담당자에게 넘깁니다. 현재는 판교박물관 공식 자료 두 페이지가 범위입니다. 다음 단계는 실제 모델과 별도 평가 사례로 정확도, 개입 횟수, 시간·비용을 비교하는 것입니다.”

## 시연 전 확인

- 브라우저에 ‘데모’ 표시가 보이는지 확인한다.
- 실제 AI 모드는 키·모델·가격·비용 설정을 모두 갖춘 후 별도로 검증한다.
- `outputs/`와 `data/`는 로컬 파일이다. 다른 기기로 옮길 때 다시 생성하거나 별도 복사한다.
- 데모는 자동 게시하지 않는다. 승인 기록은 로컬 담당자 확인 기록이며 인증된 서명이 아니다.
