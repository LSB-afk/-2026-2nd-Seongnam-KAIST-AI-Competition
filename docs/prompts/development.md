# 다음 개발을 이어갈 때 사용하는 프롬프트

개발 에이전트가 현재 구현과 사용자 요청을 이어가기 위한 지침이다. 앱의 텍스트 모델 지시는 `src/lib/prompts.ts`, 이미지 지시는 `src/lib/image-provider.ts`에서 관리한다.

먼저 [관광 플랫폼 설계](../superpowers/specs/2026-09-13-tourism-platform-design.md)·[구현 계획](../superpowers/plans/2026-09-13-tourism-platform.md), [장소·사진 출처](../place-sources.md), [디자인 참조](../design-references.md)를 읽는다. 초기 박물관 사례는 현재 제품의 단일 장소 제한이 아니다.

```text
성남 타임스토리의 현재 브랜치와 문서·테스트를 읽고, 사용자가 요청한 개선을 구현부터 검증까지 완료하라. 기존 사용자 변경을 보존하고 지정된 파일 소유 범위를 지킨다.

사용자가 Codex Goal 추적을 요청했다면 구체적인 목표와 종료 조건으로 이어간다. 활성 Goal을 중복 생성하지 않고, 구현·필수 검증이 남아 있으면 완료로 표시하지 않는다. Goal 사용을 일반적인 개발 요청에서 임의로 추가하지 않는다.

현재 제품은 공식 확인된 성남 관광지 8곳의 탐색·상세·사진 기반 한국어 카드뉴스 4장·마지막 상상 장면·담당자 승인·로컬 실행이다. 대시보드와 제작 기록은 저장된 Run에서 집계한다. 실제 OSM 지도와 목록·필터·선택 상태를 연결하고 모바일에서도 작업을 이어갈 수 있게 한다. 등록되지 않은 장소 자동 확장·로그인·공개 배포·SNS 게시·새 의존성을 임의로 추가하지 않는다.

AI 에이전트 화면은 기존 여섯 도구의 역할과 실제 작업 이벤트·비용·검수/승인 상태를 보여준다. 화면 안내 캐릭터 타미와 제작 에이전트의 역할을 구분하고, 메뉴 이동·새로고침·뒤로 가기에서 작업과 입력 초안을 보존한다. 현재 버전과 일치하지 않는 검수를 최신 검수처럼 표시하지 않는다.

README.md, docs/agent-rules.md, docs/implementation-spec.md, docs/evaluation.md와 관련 코드를 확인한다. 변경한 동작의 의미 있는 회귀 사례를 먼저 확인한다. 독립 작업의 병렬 위임은 사용자·AGENTS.md 지침과 현재 실행 범위를 따르고, 공통 타입·상태 전이는 한 책임자가 통합한다.

장소 ID와 이름을 일치시키고 선택한 장소의 사실·사진·출처를 사용한다. 미확인 운영정보는 null로 유지한다. 자료 수집은 선택한 장소의 등록된 공식 읽기 전용 URL만 허용하며 리디렉션도 검사한다. 일반 웹 검색으로 확대하지 않는다. 인용·본문 위치·출처 해시·검색 이력을 보존하고 기존 스냅샷을 덮어쓰지 않는다. 새 근거 없는 검색은 무한 반복하지 않는다.

제목·본문·대본의 사실을 각각 검수한다. 사실 전체가 지지되면 supported, 반박 근거가 있으면 contradicted, 정보가 부족하면 insufficient다. 공식 URL, 일부 진실, 상상 라벨만으로 주장을 통과시키지 않는다. 모델 검수 출력도 서버에서 참조·위치·누락을 확인한다.

문구 수정은 명시한 카드·주장에 제한하고 사람 편집은 보호한다. 이미지 수정은 지정 카드의 이미지만 바꾸며 문구·다른 카드와 과거 버전을 보존한다. 어느 쪽이든 변경 시 새 버전에서 검수·승인·출력 연결을 무효화한다. 문구 모델은 선택한 사진·크롭을 바꾸지 못한다. 오래된 요청과 늦게 온 생성 결과는 버전을 검사한다.

설명 방식은 standard/easy로 저장한다. 기존 결과를 쉬운 설명으로 바꾸는 작업은 명시적 요청과 버전 검사를 거치고, 보호 카드·사진·주장 연결·날짜·수량·한정 표현을 보존한 뒤 다시 검수한다. 변환 전 사용자 입력을 조용히 덮어쓰지 않는다. 준비된 fixture 어휘 변환과 실제 모델의 의미 보존 검증을 구분한다.

사진은 자산별 저작자·원출처·라이선스를 표시한다. 업로드는 사용·수정 권한 확인 후 raster 바이트·크기·해상도를 검증하고 재인코딩한다. 렌더러는 검증한 로컬 바이트만 사용한다. CC BY-SA 사진의 파생 이미지에는 원사진 조건이 이어지며 AI 생성 표시로 지우지 않는다. 참조 이미지의 출처·권리·해시와 생성 프롬프트를 보존한다.

AI 이미지에는 장소·주제·구도·조명·색감·질감·참조 사진·문구 여백·상상 여부를 전달한다. 참조 사진은 URL 문구가 아니라 실제 이미지 입력으로 보낸다. 한글은 별도 합성하며 AI 이미지와 실제 사진을 구분한다. 실패·취소 시 기존 이미지를 유지하고 유료 호출을 자동 재시도하지 않는다.

텍스트·이미지 호출 전 비용을 예약·저장한다. 이미지 호출도 실행 예산과 누적 시간에 합산한다. 사용량 미확인·취소·파싱 실패 기록을 보존한다. fixture는 장소별 준비 문구와 결정적 시나리오이며 자유 입력 생성이나 실제 AI 성능을 입증하지 않는다. API 설정이 없으면 가능한 로컬·모의 검증을 끝내고 실제 텍스트/이미지 API와 생성 품질만 미검증으로 명시한다. 실제 호출 실패를 데모 응답으로 바꾸지 않는다.

핵심 회귀 → 전체 테스트 → 타입·린트·빌드 → production E2E → 평가 순서로 확인한다. 1440/1024/390 화면, 실제 PNG, 사진·크롭·귀속정보, 장소 전환·기록 재진입·재검수·승인·ZIP을 확인한다. 자동화 지도 타일은 모의 응답을 사용한다. Node 24 이상 로컬 서버의 검증을 외부 배포 완료로 표현하지 않는다.

실제 결과에 맞춰 문서와 시연을 갱신한다. 최종 보고는 구현·검증 결과, 실제 API 설정으로 남은 검증, 변경 파일과 재현 명령을 구분한다. 실행하지 않은 테스트 수치·AI 품질·시간 절감을 만들지 않는다.
```
