# 성남 타임스토리 — 성남 문화홍보 AI PD

기준일: 2026-09-14. 현재 구현을 설명하는 출품 기획안이다. 주요 사용자와 문제는 현장 확인 전 가설이며, 실제 모델 성능·담당자 업무 개선 효과는 미측정이다. [1쪽 제안 요약](competition-brief.md) · [구현 명세](implementation-spec.md) · [평가 기록](evaluation.md) · [3분 시연](demo.md)

## 1. 누구의 어떤 작업을 돕는가

**우선 사용자 가설은 성남 문화시설·지역기관의 문화홍보 담당자**다. 담당자는 장소의 공식 자료를 찾고, 독자에 맞는 문구를 작성하고, 사실과 표현을 검토한 뒤 홍보물을 전달한다. 이 과정에서 자료 확인과 수정이 반복되어 제작 부담이 크다는 가설을 검증하려 한다. 아직 담당자 인터뷰나 실제 업무 시간 측정을 수행하지 않았으므로 이를 확인된 지역 문제로 단정하지 않는다.

**수혜자는 지역문화 정보를 접하는 시민**이다. 첫 콘텐츠 평가의 독자로 청소년을 우선 검토하되, 실제 기관의 수요에 따라 정한다. 담당자 제작 시간 감소와 시민의 이해·참여 증가는 서로 다른 효과다. 전자를 측정해도 후자가 입증되는 것은 아니다.

성남 타임스토리는 공식 자료와 작성 문장을 연결하고, 부족한 근거를 다시 확인하거나 해당 문장을 수정·보류하는 제작 도구다. 담당자는 출처와 수정 이력, 미해결 항목을 보고 최종 결과를 확인한다. 앱의 승인은 로컬 확인 기록이며 기관의 공식 게시 승인을 대신하지 않는다.

## 2. 현재 구현 범위

등록 장소는 판교박물관·율동공원·중앙공원·성남아트센터·모란민속5일장·성남시청·봉국사 대광명전·망경암의 8곳이다. 등록된 공식 자료와 실제 사진을 사용하며, 전국 관광지 자동 수집 서비스는 아니다. 자료와 사진 이용 조건은 [장소·사진 출처](place-sources.md)를 따른다.

사용자는 장소를 선택하고 **장소 소개·방문 안내·청소년 이야기** 중 목적을 고른 뒤 대상과 요청을 조정한다. 결과물은 한국어 카드뉴스 4장(1080×1080 PNG), 장별 문구·대본, 문장별 근거·출처, 검수·수정 이력과 ZIP이다. 마지막 장의 미래 문화공간 문구는 상상으로 표시한다. 실제 장소 사진과 AI 생성 이미지의 구분은 문구의 사실·상상 구분과 별도로 유지한다.

| 화면·기능 | 맡는 역할 |
| --- | --- |
| 지도·장소 목록·상세 | 장소와 공식 자료를 선택하는 진입점 |
| 타미 | 현재 화면과 작업 상태에 맞는 사용 안내. 모델을 호출하는 대화형 AI는 아님 |
| 핵심 AI 흐름 | 공식 근거 탐색, 대상에 맞는 작성, 주장 검수, 문제별 재탐색·수정·보류 |
| 검토·사진 편집·파일 | 담당자의 원문 확인, 수정, 버전별 재검수와 결과 전달 |

지도와 타미는 제작을 돕는 기능이다. 공모전에서 설명할 핵심은 **근거와 검수 결과에 따라 다음 행동이 달라지는 제작 과정**이다.

## 3. AI가 판단하는 지점과 종료 조건

총괄 판단, 문구 작성, 원자 주장 검수를 분리하고 네 도구를 사용한다. 아래는 구현된 live 실행 구조이며, 실제 공급자 연결에서의 판단 품질은 아직 확인하지 않았다. 데모는 같은 실행 구조를 준비된 응답과 규칙으로 재현한다.

| 입력·상황 | 다음 행동 | 남기는 근거 |
| --- | --- | --- |
| 선택 장소·목적·독자·공식 자료 범위 | `search_sources`로 필요한 원문 탐색 | 공식 URL, 본문 스냅샷, 인용 위치·확인 기록 |
| 사용할 원문 근거 확보 | `compose_story`로 장별 작성 | 문구·주장·근거 연결, 콘텐츠 버전 |
| 새 초안 또는 수정본 | `verify_content`로 제목·본문·대본의 사실을 분해해 검사 | 지지·충돌·불충분 판정, 인용·짧은 판단 이유 |
| 근거 부족 또는 충돌 | 추가 탐색, 문제 문구 수정, 또는 담당자 검토로 전달 | 검색 결과, 수정 전후, 해결·미해결 항목 |
| 현재 버전 검수 통과 | `render_cards`로 출력 후 승인 대기 | PNG·ZIP, 출력·검수 버전과 해시 |

근거 부족은 거짓으로 확정하지 않는다. 사실·비유·상상을 구분하되 상상 문장 안의 실제 사실도 검수한다. 담당자가 편집한 카드는 자동으로 덮어쓰지 않고 변경 제안을 남긴다. 문구나 사진 변경은 이전 승인·검수·출력 연결을 무효화하고 재검수를 요구한다.

서버는 현재 버전 검수, 미해결 항목 없음, 파일 구성과 버전 일치를 확인해야 승인 대기로 전환한다. 도구 12회·모델 30회·자동 수정 3회·누적 실행 180초와 설정한 비용 상한을 적용하며, 근거 미확보·반복 검색·상한 도달 시 검토 필요 상태로 멈춘다. 자동 검수 통과는 사실의 무오류 보장이 아니다.

## 4. 근거를 보이며 수정하는 시연

판교박물관의 준비된 오류 사례를 사용한다. 다음 문장은 확인된 역사적 사실이 아니라 **검수 기능을 보여주기 위해 주입한 오류**다.

> 이 문화유산의 기술이 오늘날 판교 AI 산업으로 이어졌다.

시연은 해당 문장과 근거를 나란히 보여주고, 역사적 계승을 입증할 근거가 없다는 문제를 확인한 뒤, 추가 탐색과 문제 문구의 수정·재검수 이력을 보여준다. 수정본은 실제 실행 기록에서 가져오고 미리 정한 문장을 모델의 자발적 결과처럼 소개하지 않는다. 해결되지 않으면 보류 상태와 담당자가 확인할 내용을 보여준다.

현재 기본 시연은 fixture다. 실제 모델 기록을 확보하면 모델·생성 시각·입력·자료·프롬프트 버전과 함께 제시한다. 저장 결과나 녹화는 실시간 실행과 구분한다. [시연 대본](demo.md)에 모드별 설명을 정리했다.

## 5. 무엇으로 효과를 판단할 것인가

| 확인할 질문 | 준비한 방법 | 현재 근거 수준 |
| --- | --- | --- |
| 담당자가 실제로 이 문제를 겪는가 | 최근 제작물 중심 인터뷰와 작업 흐름 관찰 | 미실시. [질문지·기록 양식](field-validation.md) 준비 |
| 실제 AI가 근거를 확인하고 수정하는가 | 동일 자료·모델·도구·상한의 고정 순서/에이전트 기술 비교 | 평가 코드 준비. 실제 모델 비교 미측정 |
| 현재 업무보다 승인 가능한 결과를 빨리 만드는가 | 담당자의 현재 도구와 서비스 사용을 교차 순서로 비교 | 미실시. [짝 비교 CSV](templates/field-workflow-pairs.csv) 준비 |
| 시민이 정보를 더 잘 이해하는가 | 별도 독자 평가 과제와 질문 설계 | 후속 검증. 제작 시간으로 대체하지 않음 |

실제 업무 비교에는 총 소요 시간, 담당자 수정 횟수, 사람이 원문을 대조한 미지원 사실 수·전체 사실 수, 승인 여부, API 추정 비용을 기록한다. 실패·중단·개선 없음도 포함한다. 소규모 결과는 개별값·중앙값·범위·표본 수로 제시하고 전체 기관에 일반화하지 않는다. fixture 회귀 결과와 사람 미검토 초안 라벨의 일치도는 실제 AI 성능이나 현장 효과를 입증하지 않는다.

## 6. 현장 적용 가정과 남은 확인

초기 적용은 한 기관 담당자가 로컬 환경에서 초안을 만들고, 원문과 결과를 검토한 뒤 기관의 기존 게시 절차로 넘기는 형태를 가정한다. 운영자·공식 자료 갱신 담당자·최종 승인자는 정해지지 않았고 도입 합의도 없다. 월 제작량과 예산은 실제 수요·호출 비용을 측정한 뒤 산정한다. 오류 신고 접수와 정정 책임 역시 기관과 정해야 한다.

현재 범위에는 로그인·기관 권한·공개 배포·SNS 자동 게시가 없다. 텍스트·이미지 모델 연결에는 설정과 비용 상한이 필요하며 현 환경에서는 실제 연결 검증 전이다. 설정 확보 전의 한계와 측정 기록은 [평가 문서](evaluation.md)에 유지한다.

공모전 방향은 사용자가 제공한 지역사회 문제 해결, AI 기획·제안 또는 구현, 예선 서면·본선 발표 및 시연 안내를 기준으로 한다. **공식 세부 주제·배점·제출 양식·발표 시간은 미확인**이다. 이 문서의 3분 시연이나 준비물 구성을 공식 규정으로 보지 않는다.
