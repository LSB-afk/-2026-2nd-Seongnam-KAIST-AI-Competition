# 성남 타임스토리 — 성남 문화홍보 AI PD

> 지역문화 자료를 조사하고, 사실과 상상을 구분하며, 홍보물을 제작·수정하는 AI 에이전트

- 문서 상태: 출품 주제 기획안 · fixture MVP 구현 및 검증 완료, 실제 모델 호출 검증 전
- 정리일: 2026-09-10
- 핵심 방향: 사실과 상상을 구분하는 도시문화 콘텐츠
- 예선 MVP 제안: 한 장소의 카드뉴스 제작과 오류 복구 시연
- 구현 현황과 실행 방법: [README](../README.md)

## 1. 서비스가 해결하려는 문제

지역문화 홍보물을 만들려면 공식 자료를 찾고, 대상에 맞게 이야기를 구성하고,
설명의 정확성을 확인해야 합니다. 과거 문화유산과 현재 도시 산업을 연결하거나
미래 모습을 제시할 때는 역사적 사실, 비유, 창작이 뒤섞일 수 있습니다.

성남 타임스토리는 이 과정을 맡는 **성남 문화홍보 AI PD**입니다. 사용자가
홍보 목표를 주면 AI가 자료 조사부터 스토리 기획, 콘텐츠 제작, 검수와 수정까지
수행합니다. 담당자는 출처와 수정 내역을 확인하고 공개 게시 여부를 결정합니다.

주요 사용자는 지역문화 홍보 담당자로 가정합니다. 예선 시나리오에서 콘텐츠를
접하는 대상은 청소년입니다. 실제 사용자 수요와 업무 개선 효과는 이후 검증합니다.

## 2. 사용자 요청과 결과물

### 요청 예시

> 청소년에게 판교박물관을 소개할 카드뉴스 4장을 만들어줘.
> 마지막 장에는 성남의 미래 문화공간을 상상하는 내용을 넣어줘.

### 제공할 결과물

- 카드뉴스 파일 4장
- 장별 문구와 대본
- 사실 설명에 대응하는 출처 목록과 원문 근거
- 검수 결과, 수정 전후 내용, 미해결 항목

카드뉴스 구성은 다음을 초안으로 삼되, 실제 설명은 공식 자료 확인 후 작성합니다.

| 장 | 목적 | 작성 원칙 |
| --- | --- | --- |
| 1 | 판교박물관에 대한 관심 유도 | 청소년이 이해할 질문과 도입 문구 사용 |
| 2 | 문화유산과 전시 이야기 소개 | 공식 자료에서 확인한 사실과 출처 사용 |
| 3 | 과거와 현재를 함께 바라보기 | 역사적 관계가 입증되지 않으면 비유로 표시 |
| 4 | 성남의 미래 문화공간 상상 | 창작 장면임을 명시하고 실제 사업으로 표현하지 않기 |

## 3. 에이전트가 맡는 업무

핵심은 **검수 결과를 보고 다음 행동과 도구를 선택하는 것**입니다.
기본 작업 흐름은 자료 조사 → 스토리 기획 → 콘텐츠 제작 → 검수 → 수정이지만,
문제의 종류에 따라 필요한 단계로 돌아갑니다. 파일 제작 전 문구와 근거를
점검하고, 제작 후에도 장수·표시 누락 등 최종 조건을 확인합니다.

| 상황 | 에이전트의 판단과 행동 |
| --- | --- |
| 문화유산 설명에 자료가 필요함 | 공식 박물관·문화유산 자료를 검색하고 원문 근거 저장 |
| 청소년에게 설명이 어려움 | 용어, 이야기 구성, 문장 길이 조정 |
| 과거와 현재를 연결할 근거가 부족함 | 추가 검색 후 역사적 관계인지 비유인지 구분 |
| 미래 장면이 실제 사업처럼 표현됨 | 공식 계획 여부를 확인하고 창작이면 상상임을 표시 |
| 검수에서 문제가 발견됨 | 해당 문장이나 장면 수정 후 재검사 |
| 제작 조건을 충족함 | 카드뉴스 파일·대본·출처·검수 내역을 묶어 제공 |
| 반복 또는 비용 상한에 도달함 | 작업을 멈추고 미해결 항목과 근거를 담당자에게 전달 |

## 4. 최소 구현 구조

**총괄 에이전트 1개와 도구 4개**로 시작합니다. 총괄 에이전트는 사용자 목표,
수집한 근거, 초안, 검수 결과, 남은 예산을 바탕으로 다음 도구 호출을 결정합니다.

| 구성 | 맡는 역할 | 주요 출력 |
| --- | --- | --- |
| 자료 검색 도구 | 성남 공식 자료 검색 및 원문 확인 | 출처 URL, 문서명, 확인일, 관련 근거 |
| 스토리 구성 도구 | 대상과 목적에 맞는 장면·대본 작성 및 수정 | 장별 문구, 대본, 사실·비유·상상 구분 |
| 근거 검사 도구 | 사실, 연결 관계, 창작 표시, 요청 조건 점검 | 문제 위치, 근거, 수정 필요 사항 |
| 콘텐츠 제작 도구 | 검수한 내용을 카드뉴스 파일로 출력 | 카드뉴스 파일과 제작 결과 |

도구 선택 이유와 실행 결과, 수정 전후 내용을 기록해 담당자가 판단의 근거를
확인할 수 있게 합니다. 자동 검수 결과만으로 정확성을 보장하지 않습니다.

## 5. 차별점: 사실과 상상을 구분하고 오류를 복구

콘텐츠에서는 다음 세 가지를 구분합니다.

- **사실:** 공식 자료에서 확인한 설명. 문장에 대응하는 출처와 근거를 보관합니다.
- **비유:** 과거와 현재를 이해하기 위한 표현. 역사적 계승이나 인과관계로 단정하지 않습니다.
- **상상:** 미래 문화공간 등 창작 장면. 실제 계획과 혼동되지 않도록 표시합니다.

### 오류 복구 시연

아래 문장은 검수 기능을 확인하기 위한 **의도적으로 준비한 오류 예시**이며,
확인된 역사적 사실이 아닙니다.

> 이 문화유산의 기술이 오늘날 판교 AI 산업으로 이어졌다.

1. 근거 검사 도구가 역사적 계승을 단정한 문장을 지적합니다.
2. 에이전트가 원문을 확인하고, 필요하면 추가 검색합니다.
3. 직접적인 연결 근거를 찾지 못하면 인과관계를 삭제하거나 비유로 바꿉니다.
4. 수정한 문장을 재검사하고 수정 전후 및 확인한 출처를 보여줍니다.
5. 담당자가 근거와 수정 내용을 확인합니다.

수정 표현의 예시:

> 과거의 문화유산과 오늘날 판교의 AI를 나란히 보며,
> 서로 다른 시대의 사람들이 무엇을 만들고 상상했는지 생각해 봐요.

이 문장도 실제 결과물에 넣기 전 맥락과 표현을 검수합니다. 시연에서는 오류가
미리 준비된 테스트 사례임을 밝히고, 실제 실행에서 발생한 오류와 구분합니다.
본선에서는 이러한 오류 발견과 복구 과정을 시연의 중심으로 발전시킵니다.

## 6. 예선 MVP 범위와 완료 조건

예선에서는 **한 장소, 한 대상, 한 출력 형식**에 집중합니다.

- 장소: 판교박물관
- 대상: 청소년
- 출력: 카드뉴스 4장, 대본, 출처 목록, 검수·수정 내역
- 필수 시연: 자료 조사부터 파일 제작까지 완료하고, 중간 오류 1건을 발견·수정·재검사
- 담당자 확인: 근거, 수정 내용, 미해결 항목을 확인할 수 있는 결과 화면 또는 보고서

완료 조건은 4장 파일이 생성되고, 사실 설명에 근거가 연결되며, 비유와 창작이
적절히 표시되는 것입니다. 해결하지 못한 검수 항목이 있으면 완료로 처리하지
않고 담당자 검토가 필요한 상태로 전달합니다.

반복 횟수와 실행 비용에는 상한을 둡니다. 구체적인 수치는 초기 실험 후 정하며,
공개 게시 단계에는 담당자 승인을 둡니다. 예선 MVP는 결과물 제공까지를 범위로
삼고 자동 게시, 다수 장소 확장, 영상 제작은 후속 과제로 남깁니다.

## 7. 효과 검증 계획

같은 자료와 도구를 사용하는 **고정 순서 제작 방식**과 **검수 결과에 따라
행동을 바꾸는 에이전트 방식**을 비교합니다. 모델, 입력 과제, 초기 자료,
사용 가능한 도구와 실행 예산 조건을 맞추고 동일한 기준으로 평가합니다.

| 평가 항목 | 측정 방법 |
| --- | --- |
| 잘못된 설명·근거 부족 해결 | 준비한 오류 중 해결한 비율과 최종 결과에 남은 오류 수 |
| 사람의 개입 부담 | 결과물당 담당자의 개입·수정 횟수 |
| 승인 가능한 결과물 제작 시간 | 요청부터 담당자가 승인 가능한 상태에 이르기까지 소요 시간 |
| 실행 비용 | 결과물당 모델·도구 사용 비용 |

자동 검수와 별도로 사람이 원문과 최종 결과를 확인합니다. 두 방식의 승인 가능한
결과물 비율과 실패·상한 도달 사례도 함께 기록해 성공 사례만 비교하지 않습니다.
위 항목은 평가 계획이며, 현재 측정된 성능이나 개선 수치는 없습니다.

## 8. 다음에 정할 사항

1. 판교박물관 관련 공식 자료의 수집 범위와 사용할 이미지의 이용 조건
2. 카드뉴스 파일 형식, 장별 분량, 시각 구성
3. 검수 통과 기준과 담당자 검토 화면의 최소 항목
4. 반복 횟수·시간·비용 상한과 미해결 항목 전달 방식
5. 사용할 모델과 도구 구현 방식, 비교 평가용 요청·오류 사례
