# 디자인 참조와 외부 서비스 구현 근거

확인일: 2026-09-13. 공개된 공식 설명과 API 문서를 확인했다. 로그인 후 편집기 조작, 실제 API 유료 호출, 개별 관광 사진의 사용 허가는 이번 조사에서 확인하지 않았다. 아래 **적용 방향**은 구현 권고이며, 코드 구현·브라우저 검증 완료를 뜻하지 않는다.

## 공개 화면에서 확인한 흐름

| 참조 | 공식 설명에서 확인 | 이 제품에 적용할 방향 | 확인하지 않은 사항 |
| --- | --- | --- | --- |
| Airbnb 검색 | 도시·지역 검색, 날짜·필터로 후보 좁히기, 지도 확대·이동으로 다른 숙소 탐색, 상세 정보와 지도 위치 확인 | 장소 검색 결과와 지도 핀을 연결하고, 선택한 장소의 정보·사진 확인으로 이어지게 한다. | 실제 로그인 UI, 목록과 지도 사이의 정확한 동기화 규칙, 화면 비율·애니메이션 |
| Adobe Express 콜라주 | 사진 추가 → 격자 선택·사진 교체·간격·크롭 조정 → 추가 편집 또는 다운로드 | 사진 선택, 프레임 배치, 문구 편집, 결과 다운로드를 분리하고 변경 결과를 미리 보여준다. | 실제 편집기 세션, 저장·로그인 흐름, Adobe 자산 재사용 권한 |
| 한국관광콘텐츠랩 | 공식 사이트의 존재와 서비스명 확인. 현재 본문은 동적 앱으로 제공되어 이번 텍스트 열람에서 세부 기능 확인 불가 | 장소 자료에 원문 링크, 출처, 사진 이용 조건을 별도로 보관한다. | 현재 API 상세 스키마·사진 다운로드 약관·로그인 기능. 검색 결과의 요약만으로 현재 UI를 관찰했다고 주장하지 않는다. |

근거: [Airbnb 검색 도움말](https://www.airbnb.co.uk/help/article/252), [Adobe Express 콜라주 안내](https://www.adobe.com/express/create/photo-collage), [한국관광콘텐츠랩](https://api.visitkorea.or.kr/).

사진 선택과 편집 단계는 위 공개 설명에서 가져온 방향이다. 지도·카드 배치, 장소 중심의 사진 프레임, AI 배경 생성 흐름은 이 제품의 설계 판단이며 참조 서비스에서 관찰한 기능으로 소개하지 않는다. 브랜드 그래픽이나 샘플 사진을 복제했다는 의미도 아니다.

## 관광 사진의 이용 범위

공식 기존 관광사진갤러리 안내는 공공누리 표시가 있는 사진은 해당 유형 조건을 따르고, 표시가 없으면 공사에 이용 범위를 확인하도록 설명한다. 1유형은 출처 표시와 함께 상업 이용·변경이 가능하고, 2유형은 비상업 이용만 가능하다. 3·4유형은 변경과 2차 저작물 작성을 금하며, 4유형은 상업 이용도 금한다. 갤러리는 촬영자 크레딧, 신청 용도 제한, 제3자 제공 제한도 명시한다. [공식 관광사진갤러리 이용·저작권 안내](https://english1.visitkorea.or.kr/kor/tt/pr_gallery/new_photo_gallery/menu_plan/plan_list.jsp?TITLE=%ED%83%9C%ED%99%94%EA%B0%95+%EA%B5%AD%EA%B0%80%EC%A0%95%EC%9B%90&category=46705&gotoPage=4&menu=2019&rows_page=12&searchWord=&sort=createdTime+DESC&vTyp=viewVer)

별도의 기존 공사 홈페이지 콘텐츠 안내도 사전 허가와 용도 제한을 명시한다. 이는 해당 페이지의 안내이며, 현재 콘텐츠랩이나 모든 TourAPI 사진에 동일한 조건이 일괄 적용된다고 단정할 근거는 아니다. [공사 홈페이지 콘텐츠 이용안내](https://kto.visitkorea.or.kr/kor/helpDesk/siteGuide/contentsGuide.kto)

구현 권고:

- `sourceUrl`, `credit`, `licenseType`, `licenseUrl`, `derivativeAllowed`, `verifiedAt`를 사진별로 보관한다. 미확인은 허용으로 해석하지 않는다.
- 장소 메타데이터가 공개되어 있다는 사실과 사진 변형·재배포 허용을 구분한다. 사용자가 권한을 가진 업로드 사진으로 편집을 수행할 수 있게 한다.
- AI 편집에 원본을 전송하는 권한과 결과물에 원본을 포함해 배포하는 권한도 확인한다. 변경 금지·사용 불가 자료를 자동 수집하거나 편집 참조로 전송하지 않는다.
- 이번 조사는 특정 관광 사진의 이용 허가를 취득하거나 인증하지 않았다.

## OpenStreetMap 래스터 타일

공식 정책의 적용 대상은 OSM 데이터 전체가 아니라 `tile.openstreetmap.org` 서비스다. HTTPS 표준 URL, 눈에 보이는 출처 표시, 웹의 유효한 Referer, HTTP 캐시 준수가 필요하다. 브라우저 기본 User-Agent는 허용된다. 캐시 헤더를 읽을 수 없는 구현은 최소 7일 캐시해야 한다. 기본 no-cache 요청, Referer 차단, 사전 타일 수집, 대량 다운로드, 오프라인 저장은 금지한다. 제공은 최선 노력 방식이며 SLA가 없다. [OSMF Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)

가벼운 브라우저 지도 구현에 적용할 사항:

- 타일은 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`에서 현재 사용자가 보는 영역만 불러온다. 타일 URL은 교체할 수 있도록 둔다.
- 지도 위에 `© OpenStreetMap contributors`를 표시하고 [저작권 페이지](https://www.openstreetmap.org/copyright)로 연결한다. 버튼이나 패널이 가리지 않게 한다.
- 브라우저의 정상 이미지 요청·캐시를 사용한다. `no-referrer`, `same-origin` 등 교차 출처 Referer를 없애는 설정이나 캐시 무효화 쿼리를 타일에 적용하지 않는다.
- 서비스 워커 사전 캐시, 전체 지역 다운로드, 줌 단계 미리 받기를 추가하지 않는다. 지도 자동화 검증에서는 타일 요청을 목 처리하고, 실서비스를 반복 이동·확대로 스캔하지 않는다.
- 타일 장애 시 장소 목록과 텍스트 위치는 남기고 지도 로드 실패를 표시한다.

## OpenAI 이미지 생성·참조 편집

공식 가이드는 직접 HTTP 생성 요청과 base64 이미지 결과를 문서화한다. `gpt-image-2`는 기본 세 가지 크기 외 사용자 지정 크기도 지원하지만 크기·픽셀 제약이 있다. 이 모델은 입력 이미지를 높은 충실도로 처리하므로 `input_fidelity`를 생략한다. 비용은 출력뿐 아니라 텍스트·이미지 입력에도 영향을 받는다. 최신 모델·가격은 변하므로 모델명과 예산 값을 환경 설정에서 관리한다. [OpenAI 이미지 생성 가이드](https://developers.openai.com/api/docs/guides/image-generation)

| 목적 | 요청 |
| --- | --- |
| 참조 사진 없는 생성 | `POST https://api.openai.com/v1/images/generations`, JSON `{ model, prompt, n: 1, size, quality, output_format: "png" }` |
| 사진을 실제 입력으로 사용하는 편집 | `POST https://api.openai.com/v1/images/edits`, multipart의 반복 `image[]` 파일과 `model`, `prompt`, `n`, `size`, `quality`, `output_format` 필드 |
| 편집 JSON 대안 | 같은 편집 endpoint에 `{ images: [{ image_url: "data:image/png;base64,..." }], model, prompt, ... }`. `file_id`도 지원한다. |

두 요청 모두 서버가 `Authorization: Bearer ...`를 설정한다. multipart boundary는 `FormData`가 설정하게 한다. 파일 이름이나 URL을 프롬프트 문자열에만 넣는 것은 참조 이미지 입력이 아니다.

편집 API는 GPT 이미지 모델에 최대 16개 참조를 받으며 프롬프트 최대 길이는 32,000자다. 반환값의 `data[].b64_json`을 디코딩한다. GPT 이미지 모델은 생성 결과의 URL 응답 형식을 지원하지 않는다. 표준 출력 크기는 `1024x1024`, `1536x1024`, `1024x1536`; 지원 품질과 추가 옵션은 선택한 모델에 맞춰 제한한다. [OpenAI 이미지 편집 API](https://developers.openai.com/api/reference/resources/images/methods/edit)

프로젝트 권고값과 오류·예산 처리:

- 첫 구현은 `n=1`, 위 세 크기 중 하나, 명시한 품질을 사용한다. 모델을 변경하면 지원 옵션과 비용 설정도 함께 검증한다.
- 예를 들어 참조 최대 4장·각 5 MiB·PNG/JPEG/WebP만 허용하는 앱 제한을 둔다. 이는 공급자의 공식 최대치가 아니라 메모리·지연·예산을 제한하기 위한 제품 설정이다. MIME 선언뿐 아니라 이미지 바이트·크기도 검증한다.
- 요청 전에 설정된 1회 최대 예약액을 원자적으로 확보한다. 동시에 들어온 요청도 총 한도에 포함하며, 남은 금액이 부족하면 외부 호출 전에 종료한다. 입력 사진·문구·출력 크기·품질을 제한해야 예약액의 근거를 유지할 수 있다.
- 고정 예약액은 운영자가 정한 보수적 추정치다. 실제 청구 상한 보장이라고 표시하지 않는다. 입력·출력 토큰과 계정 가격을 반영해 재검토하고, 사용량이 없으면 비용을 0으로 확정하지 않는다.
- 타임아웃·연결 단절 이후 공급자가 처리했는지 불명확하면 예약액을 즉시 반환하거나 자동 재시도하지 않는다. 실패·불명 상태와 재시도 이력을 기록한다.
- API 키 미설정은 명확한 설정 오류로 반환하고 유료 호출을 하지 않는다. 인증 실패·한도 소진·입력 오류·응답 파싱 실패를 구분한다. 테스트용 결과를 실제 생성 성공으로 표시하지 않는다.
- 반환 base64, 이미지 형식·크기·바이트 수를 확인한 후 저장한다. 사용자 문구가 필요한 프레임은 앱에서 편집 가능한 텍스트로 합성하는 방식이 적합하다.

실제 API 호출과 과금 내역 대조는 이번 문서 조사 범위 밖이다. 키 없는 동작, 모의 성공·실패 응답, 동시 예산 예약, 참조 사진이 편집 endpoint에 전달되는지에 대한 구현 검증을 별도로 수행해야 한다.
