# 성남 관광 탐색과 카드뉴스 제작

2026-09-13 사용자 구현 지시를 설계 기준으로 삼는다. 별도 승인 대기 없이 구현·검증한다.

## 제품과 화면

공식 확인된 성남 장소를 전국 지도에서 찾아 장소별 근거와 실제 사진으로 한국어 카드 4장을 만든다. 마지막 장은 상상으로 구분한다. 저장 기록 기반 대시보드 → 탐색 → 상세 → 제작 → 사진/문구 편집 → 재검수 → 승인 → PNG/ZIP 흐름을 제공한다.

고정 240px 사이드바와 목록/지도/상세 3영역을 사용한다. 1024px에서는 상세를 겹침 패널로, 390px에서는 목록/지도 전환과 상세 시트로 구성한다. 메뉴 이동은 React 상태를 유지한다. 지도는 실제 OpenStreetMap 타일과 Web Mercator 좌표 변환을 사용하며 라이브러리 추가 없이 드래그·휠·버튼·키보드 조작을 제공한다. 전국 보기와 성남 확대, 겹친 마커 묶음, 필터 결과의 목록/지도 동기화를 구현한다. 타일 실패 시 재시도와 목록을 유지한다.

지도와 성남 사진에 시각적 우선순위를 둔다. 기존 청색 브랜드를 유지한다. 색 토큰: canvas #F5F7FA, surface #FFFFFF, ink #182236, muted #667085, brand #244CC5, nature #176A59. Noto Sans KR 400/500/600/700 로컬 폰트를 사용한다. 제목 40/700, 부제목 26/600, 소제목 19/600, 본문 16/400, 보조 13/400. 출력은 별도 1080px 토큰. 포커스, 대비, keep-all+overflow-wrap, reduced-motion을 공통 적용한다.

## 데이터와 상태

정적 Place 카탈로그는 출처·확인일·실제 좌표·운영정보·사진 권리를 보존한다. Brief.placeId와 이름을 함께 검사한다. 과거 이름만 있는 실행도 읽는다. 검증되지 않은 운영정보는 null이고 UI에서는 확인 필요다. 사진은 권리가 확인된 로컬 자산만 배포한다.

Card.image는 자산 ID, 종류(photo/upload/ai), 장소 ID, 출처·권리, 해상도, SHA256, 초점 x/y 및 zoom을 갖는다. 외부 URL을 렌더러가 직접 읽지 않는다. 업로드는 raster만 크기/해상도를 제한하고 서버에서 디코딩·재인코딩하여 로컬 저장한다. 렌더러는 검증된 로컬 바이트를 data URI로 포함한다. 브라우저 미리보기와 PNG는 같은 crop 수식을 사용한다.

이미지 교체·크롭·생성 완료는 한 카드만 변경하고 문구와 다른 카드를 보존한다. 콘텐츠 버전을 올리고 검수·승인·아티팩트를 무효화한다. 이미지 작업의 예약 비용과 호출 로그는 기존 실행 예산에 합산한다. API 미설정, 실패, 재시도, 중복, 취소, 늦은 결과에 대한 버전 검사를 제공한다. 생성 이미지는 AI 생성, 마지막 장은 상상 이미지로 구분하며 실제 사진을 상상 결과로 오인시키지 않는다.

## 검증과 종료 조건

다른 장소 선택 시 판교 내용이 섞이지 않는 회귀, 장소 ID/이름 불일치 차단, 이미지 파일/권리/경로·크기 검증, 크롭·교체·생성 시 버전과 편집 보호, 비용 예약·취소 모의 테스트를 추가한다. 기존 4장/검수/승인/ZIP 테스트를 유지한다. npm test, typecheck, lint, build, test:e2e와 변경된 fixture 평가를 수행한다. 1440/1024/390 화면과 실제 PNG를 직접 확인한다. 외부 이미지 API 설정이 없으면 실제 생성 품질을 미검증으로 명시하며 연결 코드와 모의 검증을 완료한다. 핵심 구현이나 필수 검증이 남으면 Goal을 완료하지 않는다.
