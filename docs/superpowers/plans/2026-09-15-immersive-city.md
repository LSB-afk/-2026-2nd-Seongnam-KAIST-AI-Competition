# 화면 전체에 펼쳐지는 성남 3D 여행

최신 요청: 3D 지도를 브라우저 화면 전체로 확장하고 기존 대시보드와 조작 UI를 지도 위에 배치한다. 사용자 제공 두 화면은 현재 상태의 근거이며 기존 페이지 격자를 유지하라는 참조가 아니다.

## 구현 결정

- 3D 화면에서만 기존 사이드바·상단바·푸터의 공간 예약을 해제한다. 캔버스는 뷰포트 전체를 차지하고 다른 화면은 현재 구조를 유지한다.
- 주 메뉴는 왼쪽 위 `주 메뉴 열기` 버튼의 팝오버. 오른쪽 위에서 명소 패널을 접고 펼친다. 지도·메뉴 간 이동 시 기존 URL과 저장 상태를 보존한다.
- 제목·지역 선택은 상단의 작은 패널, 명소·실제 사진·제작 버튼은 오른쪽 스크롤 패널, 감상 조작은 하단의 작은 패널. 설정은 펼쳐 쓰고 패널 밖에서는 지도를 바로 조작한다.
- 모바일 명소 정보는 접을 수 있는 하단 시트. 페이지 자체는 스크롤하지 않고 패널 내부만 스크롤한다. 충분한 지도 조작 영역과 44px 수준 터치 대상을 확보한다.
- 패널은 일반 정보 영역이며 모달로 잠그지 않는다. 접힌 콘텐츠는 초점 순서에서 제외하고 닫을 때 열기 버튼으로 초점을 돌린다. 메뉴는 Escape와 바깥 클릭으로 닫힌다.

## 작업 소유

Root: 앱 셸(page.tsx·diorama-shell.css), 회귀/E2E, 디자인 기록, 통합 시각 검수와 최종 실행.
Frontend executor: diorama-page.tsx·diorama.css의 화면 전체 지도와 떠 있는 패널. 도시 모델/renderer/tour는 수정하지 않는다.

통합 검수에서 태블릿의 긴 명소 패널을 타미가 가리는 문제를 재현했다. Frontend executor의 후속 범위를 기본 타미 위치의 장애물 회피와 해당 회귀 테스트로 한정해 확장한다. 사용자가 직접 지정한 타미 위치는 유지한다.

## 완료 기준

1440×1000, 1024×900, 390×844에서 실제 WebGL 캔버스가 뷰포트 네 가장자리에 맞는다. 페이지 넘침이 없고 패널을 접거나 여는 중에도 같은 캔버스를 유지한다. 패널에서 명소·설정을 선택할 수 있고 빈 지도에서는 드래그·핀치·키보드가 동작한다. 장소 정보·사진·카드뉴스 연결, 11개 감상 지점, 주 메뉴 이동/복귀, 오류 복구가 유지된다. 관련 회귀·lint·typecheck·build 및 화면 검수 후 기존 로컬 서버를 새 빌드로 갱신한다.

## 완료 기록

2026-09-15 완료. 단위·회귀 418개, 전체 Chromium E2E 50개, 최종 서버의 리사이즈 초점 회귀 3회 연속 통과. 전체 lint·TypeScript·프로덕션 빌드 통과. 최종 서버에서 세 화면 크기와 모바일 회전·핀치를 검증했으며, 동일 캔버스·페이지 넘침 없음·브라우저 오류 없음·스크롤 0을 확인했다.

앱 셸은 3D 화면에서만 화면 전체를 사용하며, 대시보드 UI는 접을 수 있는 패널로 정리했다. 긴 명소 패널에 대한 타미의 위치 보정, 화면 폭 전환 시 초점 복원, 오류 알림의 버튼 겹침도 수정했다. `http://127.0.0.1:3000/?view=diorama&scene=seongnam`에서 새 프로덕션 빌드를 실행 중이다. 검증 자료는 `outputs/seongnam-immersive-development/`에 보관한다. 실제 휴대폰·Safari·GPU 성능 검증은 수행하지 않았다.
