# 성남 문화홍보 AI PD Implementation Plan

**Goal:** API 키 없이 전체 시연이 가능한 카드뉴스 제작·검수 앱 및 설정 가능한 live 경로 구현.
**Architecture:** 공유 Run 계약을 순수 에이전트, 서버 저장/API, 렌더러, 화면이 사용한다.
**Tech Stack:** Next.js, TypeScript, Node 24 SQLite, Playwright, Vitest.
**Spec:** ../../implementation-spec.md

- [x] 에이전트: tests/agent.test.ts에 정상/오류 분기/상한 실패 사례를 쓰고 실패를 확인한다. src/lib/agent.ts, verifier.ts, fixture.ts, provider.ts에 runAgent(run, deps)를 구현한다. 루프 결과와 live 설정 실패를 검증한다.
- [x] 렌더링: tests/render.test.ts에 HTML escape/버전 불일치 실패를 작성한다. src/lib/render.ts에 renderCards(run, signal)를 구현한다. 실제 PNG 4장 및 ZIP을 생성해 글꼴·크기·잘림을 검증한다.
- [x] 서버: tests/store.test.ts, tests/service.test.ts에 중복 요청/승인/수정 무효화/취소/복구 사례를 작성한다. src/lib/store.ts, service.ts와 src/app/api 라우트를 구현한다. SQLite 임시 디렉터리에서 검증한다.
- [x] 화면: src/app/page.tsx, layout.tsx, globals.css에 3영역 제작실을 만든다. tests/e2e.spec.ts에서 fixture 실행, 출처, 수정, 재검수, 승인, 다운로드를 검증한다.
- [x] 통합: typecheck/lint/test/build/E2E를 실행한다. scripts/evaluate.ts, README 실행 방법과 docs/demo.md를 작성한다. 실제 이미지와 화면을 확인하고 남은 제한을 기록한다.

검증: production build 기반 브라우저 E2E 4개 통과. 실제 공식 자료 2곳 수집 및 근거 3건 확인. fixture 12개 비교 실행 완료. 실제 모델 호출은 키가 없어 미검증이며 README에 명시한다.
