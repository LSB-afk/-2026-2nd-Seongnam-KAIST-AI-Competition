# 성남 3D 여행 독립 화면 구현

2026-09-15. 사용자가 상세 개발 프롬프트를 검토한 뒤 개발 시작을 요청했다. 최신 요구는 별도 주 메뉴 `성남 3D 여행` 및 독립 화면이다. 이전 분석의 탐색 내부 presentation 전환 제안을 대체한다.

## 범위와 완료 기준

- `view=diorama` 독립 메뉴. 장소·관찰 지점의 URL/저장/뒤로 가기 복원. 기존 agent 화면, readingStyle, 제작 중 방어 및 저장 데이터 보존.
- 판교박물관, 중앙공원, 모란민속5일장의 서로 다른 실제 3D 모형. 실사진에 근거한 축약 표현이며 실제 배치·치수·보이지 않는 내부 복원으로 표시하지 않음.
- 클릭/키보드 장소·관찰 지점 선택, 카메라 이동·회전·확대·초기화, 자동 감상·정지·재개·다음·종료, 속도와 감상 시간 분리.
- 이름표/관광객/움직임 설정, reduced-motion, 탭 숨김/화면 이탈 중단, 오래된 요청 무시, context loss/렌더러 실패 대체 화면.
- 실제 사진·공식 설명·출처, 실제 위치 단일 핀, 기존 타미 문맥, 동일한 장소로 카드 제작.
- 1440/1024/390 화면·실제 WebGL 렌더·터치/키보드·회귀 테스트와 lint/typecheck/build 검증.

## 결정

- 현 React 19.3 유지. 공식 배포 계약을 재확인한 Three 0.186.0와 @types/three 0.186.0만 직접 추가. Fiber9.7의 React<19.3 제약 때문에 강제 설치하지 않음.
- 장소별 모형은 코드로 제작하는 실제 Three 기하 자산. 외부 GLB 로딩이 필요하지 않은 첫 범위에서 사용하지 않는 로더를 추가하지 않음. 장면 생성 모듈 지연 로딩 실패와 WebGL 실패를 처리.
- 한 화면에는 선택 장소의 모형 하나만 유지. 3개 장면을 실제 도보 코스처럼 인접 배치하지 않음.
- 제어 UI는 HTML. 독립 diorama 선택을 workspace에 추가하고 기존 explore 필터와 분리.
- 기존 작업은 원본에서 수정하지 않고 별도 worktree의 기준 snapshot 1e3489e 위에서 작업. 최종 반영 시 원본의 추가 변경을 확인하고 해당 작업 diff만 합성.

## 시각 기준

기존 Noto Sans KR, 짙은 초록 글자 #173f39, 밝은 안개색 장면 #edf3ef, 숲 #5c896b, 호수 #8bbdc1, 작은 황금색 강조 #e8b75f. 사용자 참조 영상의 모형이 주인공인 구성 유지. 별도 반복 카드 장식보다 넓은 3D 무대와 읽기 쉬운 정보 영역에 집중한다.

큰 화면: 제목/장소칩 → 3D 무대와 옆 설명 → 아래 재생 컨트롤. 작은 화면: 장소칩 → 무대/컨트롤 → 접을 수 있는 실제 정보. 타미·지도 출처·컨트롤 겹침 검수.

## 위험과 검증

모형 관찰 지점은 실제 자료가 증명하는 외관/풍경 설명으로 제한한다. 미니지도 단일 핀과 축약 모형의 좌표를 혼합하지 않는다. 매 프레임 React setState를 하지 않으며 소유 자산/루프/이벤트 정리를 검증한다. 앱 구현 완료를 기존 332개 기준 테스트 통과로 대신하지 않고 신규 단위/E2E와 실제 브라우저 화면으로 입증한다.
