# 성남 전체를 하나의 3D 도시로 확장

사용자 최신 요청(2026-09-15): 영상처럼 성남시 전체를 한 화면에 구현하고 고도화한다. `DESIGN.md`의 도시 전체→지역→명소 흐름을 적용한다. 기존 구현을 보존한 백업은 `outputs/seongnam-city-development/baseline.zip`이다.

## 결정과 이유
기존 Three 렌더러 안에 전체 도시를 한 번 생성한다. 출처 있는 구 경계·기존 검증 장소 좌표, 축약된 도로/탄천/녹지, 인스턴싱 건물을 결합한다. 장소별 모형 교체는 전체 도시 연속성을 깨므로 종료한다. 정밀 디지털 트윈 서비스/신규 지도 SDK는 API 키·자산/성능 비용이 요청 범위를 넘으므로 추가하지 않는다.

## 구현 계약
`DioramaSelection.placeId`에 `seongnam`과 기존 검증 8곳. `seongnam`의 hotspot은 `sujeong`, `jungwon`, `bundang` 또는 null. 기존 URL은 호환하며 첫 진입 기본값만 전체 보기로 변경. 데이터는 같은 투영 좌표를 모델·카메라·이름표가 공유한다. 선택 장소의 실제 위치 지도는 기존 위경도 기반 임베드를 유지한다. 기존 3모형과 새 5개 상징 모형을 같은 도시 안에 유지한다. 새 모형은 공식 위치/설명에 근거한 상징이며 치수/형태는 축약임을 표시한다.

## 소유와 순서
1. Root: 상태·자료 계약, 디자인, UI, 통합·회귀 검증.
2. Researcher: 공식 지리 근거·재사용 가능한 구 경계와 출처 문서.
3. Executor/model: city-model.ts와 모형 검증. 전체 도시·탄천·건물·녹지·랜드마크 자원 관리.
4. Executor/renderer: renderer.ts 및 렌더러 테스트. 단일 도시 유지·전체/구/명소 카메라와 라벨.
5. 독립 reviewer: 통합 후 읽기 전용 리뷰.

## 완료 기준
- 기본 URL에서 세 구가 하나의 실제 WebGL 캔버스에 동시에 보인다.
- 전체→각 구→8개 명소→관찰 지점→전체로 모델 재생성 없이 이동한다.
- URL/뒤로 가기/저장/동일 장소 카드 제작 및 자동 감상 상태 계약을 검증한다.
- 도시 경계·지리 투영·리소스 해제와 카메라 목표의 단위 검증. 1440/1024/390 스크린샷과 실제 캔버스 픽셀/입력 검증. 현재 전체 회귀 및 lint/typecheck/build 통과.
- 최종 보고에 지리 자료 버전·축약 범위·검증 한계를 명시한다.
