# 성남 타임스토리 — 관광 탐색과 카드뉴스 제작

성남의 관광지를 지도에서 찾고, 장소 2~3곳의 공식 근거·사진·메모를 연결해 카드뉴스 4장을 만드는 로컬 웹 앱입니다. 마지막 장은 상상으로 표시하며, 문구·사진 편집 후 재검수와 담당자 승인을 거쳐 PNG·ZIP을 내려받거나 카드와 3D 장면을 함께 재생합니다. 한 장소만 소개하는 기존 제작도 지원합니다.

[공모전 제안 요약](docs/competition-brief.md) · [현장 검증 양식](docs/field-validation.md) · [구현 명세](docs/implementation-spec.md) · [판단·검수 규칙](docs/agent-rules.md) · [장소·사진 출처](docs/place-sources.md) · [디자인 참조](docs/design-references.md) · [평가](docs/evaluation.md) · [3분 시연](docs/demo.md) · [개발 재개 프롬프트](docs/prompts/development.md)

우선 사용자 가설은 성남 문화시설·지역기관의 문화홍보 담당자입니다. 공식 자료 확인·작성·검토의 반복 부담을 줄이는지 검증하려 하며, 담당자 인터뷰와 실제 업무 개선 효과는 아직 측정하지 않았습니다. 시민의 이해·참여 증가는 별도 검증이 필요한 후속 효과입니다.

현재 범위는 [안내 플랫폼 설계](docs/superpowers/specs/2026-09-13-guided-platform-design.md)와 [구현 계획](docs/superpowers/plans/2026-09-13-guided-platform.md)을 따릅니다. 초기 판교박물관 기획과 평가 사례는 이력으로 유지합니다.

## 실행

Node.js **24 이상**과 Chromium이 필요합니다. Node 내장 SQLite를 사용하며 실행 환경에 따라 experimental 경고가 표시될 수 있습니다.

```bash
npm ci
npx playwright install chromium
npm run dev
```

`npm run dev`도 빌드처럼 webpack을 사용합니다. Windows 스마트 앱 컨트롤이 Turbopack에 필요한 네이티브 모듈을 차단하기 때문입니다.

[http://127.0.0.1:3000](http://127.0.0.1:3000)에서 **관광지 탐색 → 장소 선택 → 이 장소로 카드뉴스 만들기**로 이동합니다. 데모 모드는 API 키 없이 사진이 포함된 카드와 파일을 제작합니다. NAVER 지도는 공개 Client ID와 허용 도메인 등록이 필요합니다. 설정이 없으면 OpenStreetMap 공식 임베드로 기본 지도를 표시합니다. 장소 목록·상세·저장·제작·타미 안내도 사용할 수 있습니다.

**성남 3D 여행** 메뉴에서는 화면 전체의 입체 도시를 둘러봅니다. 수정구·중원구·분당구의 실제 지도 좌표에 도로·건물 외곽선·공원·수면과 **52개 명소**를 함께 표시합니다. 명소는 이름·종류·지역으로 검색하고 8개씩 넘겨 보며, 자동 감상은 55개 관찰 지점을 연결합니다. ‘가게·도로’에서는 공개 지도에 등록된 장소와 도로명을 검색해 가까운 결과 20개와 원본 출처를 확인합니다. 사람·자동차 표시, 도시 활기, 사람 크기도 조절합니다. 지도를 잡아 끌거나 빈 곳을 클릭해 이동하고, 마우스 위치에서 확대합니다. 이동·회전 모드와 위에서 보기 버튼을 제공합니다. 모바일에서는 한 손가락으로 이동하고 명소와 설정을 하단 패널로 하나씩 펼칩니다. [3D 여행 바로 열기](http://127.0.0.1:3000/?view=diorama&scene=seongnam)에서 공식 안내·위치 확인과 같은 장소의 카드뉴스 제작으로 이어집니다.

3D 지리는 저장된 OSM 자료를 사용해 API 키 없이 작동합니다. 이번 자료에는 도로 원본 way 15,100개, 건물 객체 32,300개, 이름 있는 장소 3,177개, 도로명 1,627개와 토지 피복 영역 933개가 있습니다. 성남 전체를 빠짐없이 수록한 자료는 아니며, 없는 건물 높이·도로 폭과 탄천 폭은 추정하고 사람·교통은 연출합니다. 실제 위치 지도와 공식 외부 페이지에는 인터넷 연결이 필요합니다. [기능·구조 안내](docs/diorama.md) · [모형 제작 근거](docs/diorama-assets.md) · [지리 자료 출처](docs/seongnam-urban-sources.md).

최적화한 로컬 실행은 다음과 같습니다.

```bash
npm run build
npm start
```

개발·실행 서버는 `127.0.0.1`에 바인딩합니다. 로그인, 외부 공개 배포, SNS 자동 게시를 구현하거나 수행한 것은 아닙니다.

## 도시 이야기를 만드는 다섯 가지 체험

- **내 도시 이야기**: 3D에서 명소를 골라 ‘내 이야기에 담기’를 누릅니다. 2~3곳의 순서·사진 사용·공식 자료·개인 메모·현재 지도 구도를 저장하고 작업실로 이어집니다. 앞의 세 카드는 장소별 근거를 사용하며 마지막 카드는 상상입니다.
- **3D 이야기 재생**: 작업실에서 ‘카드와 3D 장면 함께 보기’를 누르면 카드와 지도 위치가 함께 바뀝니다. 직접 지도를 조작하면 자동 재생이 멈춥니다. 최종 승인 후 링크와 QR을 만들며, 공유본에는 승인된 사진 구도와 출처도 보존합니다.
- **시간 렌즈**: ‘시간·탐정’에서 날짜가 있는 기록과 사진, 현재 지도 자료, 미래 상상 입력을 오갑니다. 기록이 없는 장소에는 빈 상태를 표시하며 오래된 사진을 오늘의 모습으로 바꾸어 소개하지 않습니다.
- **타미 탐정단**: 준비된 5개 장소에서 공식 기록에 맞는 근거를 찾고, 확인한 문장과 원문 링크가 담긴 탐험 보고서를 내려받습니다.
- **시민 기억 지도**: 장소에 짧은 기억과 사진을 비공개로 보관합니다. 권리·활용 동의와 이 기기의 검토를 마친 기억은 개인 메모로 사용할 수 있고 철회·삭제할 수 있습니다. 현재 브라우저에 저장되는 첫 버전이며 여러 시민의 기록을 모으는 공개 게시판은 아직 제공하지 않습니다.

명소는 사용 가능한 **실제 사진 8곳**과 장소 유형 아이콘으로 구분합니다. ‘먹거리’에는 성남시 선정·한국관광공사 소개·블루리본 근거가 있는 **8곳**을 일반 지도 점포와 구분해 표시합니다. 좌표를 확인한 3곳만 3D 표지와 주변 3km 검색에 사용합니다. 나머지는 성남 전체 목록에서 확인할 수 있으며, 실시간 인기 순위·대기 시간·영업 여부를 뜻하지 않습니다. [먹거리·시간 기록 출처](docs/city-story-sources.md)

공유 주소 `/stories/{id}`는 승인된 버전의 읽기 전용 화면입니다. 제작 기록을 불러오지 않으며 초안 메모·담당자 이름을 공유 데이터에서 제외합니다. `127.0.0.1` 링크는 이 컴퓨터에서만 열립니다. 앱 전체의 작성 API는 로컬 사용을 전제로 하므로 외부 공개 운영에는 별도의 접근 제어가 필요합니다.

## 화면과 제작 흐름

- **홈·대시보드**: 실제 장소 사진, 주제·지역별 탐색, 실제 검수한 데모 카드 4장, 목적별 제작과 내 작업 이어가기를 제공합니다.
- **성남 둘러보기**: 키 없이 OpenStreetMap 기본 지도의 성남·전국 보기, 확대·이동과 선택 장소 핀을 제공합니다. NAVER 설정이 있으면 공식 SDK의 다중 마커·밀집 마커 목록을 사용합니다. 등록된 52곳의 검색·지역·유형·주제 필터를 장소 목록과 지도 선택란에 함께 적용합니다.
- **저장한 장소**: 이 브라우저에 저장·해제한 장소를 다시 찾습니다.
- **장소 상세**: 주소·공식 자료·외부 길찾기와 등록된 사진·운영정보를 확인합니다. 확인하지 않은 사진·운영정보를 만들어 채우지 않습니다.
- **카드뉴스 작업실**: 장소 소개·방문 안내·청소년 이야기 목적을 대상과 실제 제작 요청에 반영합니다. 문구·사진 편집 후 재검수·담당자 승인·다운로드를 이어갑니다.
- **제작 기록**: SQLite에 저장된 최근 50개 작업을 장소·카드 제목과 상태로 검색해 다시 엽니다.
- **AI 에이전트**: 실제 실행 이벤트·자료·확인할 항목·호출 기록을 보여 줍니다. 여섯 작업 기능의 역할과 제작 에이전트·타미의 차이를 설명하고 현재 작업실의 근거 확인으로 연결합니다. 실행 완료와 담당자 승인은 구분합니다.

제작 입력의 **설명 방식**에서 기본 설명 또는 쉬운 설명을 선택합니다. 기존 결과는 **직접 수정 → 이 카드뉴스를 쉬운 설명으로 바꾸기**에서 명시적으로 변환합니다. 날짜·수치·조건·근거를 보존하고 새 버전을 재검수하며, 직접 편집한 카드와 사진·크롭은 유지합니다. 기존 승인은 해제됩니다. 데모는 준비된 문구·용어 변환이고 실제 모드는 모델 작성과 독립 검수를 사용합니다. 실제 모델의 읽기 난도와 의미 보존 품질은 별도 평가가 필요합니다.

문장별 세부 검수에서는 문장을 펼쳐 판정 이유·다음 행동·근거 구절과 원문을 대조합니다. 현재 버전·문구와 맞지 않는 판정은 현재 결과로 표시하지 않습니다. 자료 수집일과 원문 발행·수정일, 과거 검수 기록을 구분하고 제목·본문 편집으로 이동할 수 있습니다.

**타미**는 화면과 작업 상태에 맞는 도움말과 8단계 사용법을 제공합니다. 유료 생성·재검수·승인을 자동 실행하지 않습니다. 종료·이어하기·처음부터 다시하기, 최소화·움직임 끄기를 지원하며 브라우저의 동작 감소 설정을 따릅니다. 캐릭터나 사용법 버튼을 마우스·터치로 끌어 자유롭게 옮기면 위치가 저장됩니다. 클릭은 안내를 열고, 방향키는 이동, Home 키와 설정의 위치 초기화는 기본 위치 복원입니다. 대기 중에는 4px 안팎으로 천천히 움직이며 안내·조작 중에는 멈춥니다. [캐릭터·튜토리얼 설계](docs/tami-design.md)

화면·선택 장소·검색 조건·NAVER 지도 위치는 URL과 로컬 저장소에서 복원됩니다. 기본 지도의 앱 버튼으로 선택한 전국·성남 범위와 장소는 복원되지만, 임베드 내부에서 직접 이동·확대한 위치는 저장되지 않습니다. 저장한 장소·작성 중 제작 입력·작업별/카드별 미저장 문구도 이 브라우저에 보관합니다. 서버 작업과 입력 초안은 별개이며, 서버 버전이 바뀌면 이전 미저장 문구를 사용자가 명시적으로 불러올 수 있습니다. 공유 URL에는 자유 입력 문구를 넣지 않습니다.

등록 장소는 기존 8곳과 공식 자료로 확인한 신규 44곳을 합한 **52곳**입니다. 기존 장소의 사진·운영정보는 보존하고, 신규 장소의 사진·운영시간·휴무·요금은 `null`로 두었습니다. 대표 좌표는 출입구와 다를 수 있으며 일반 OSM 점포를 관광명소로 자동 등록하지 않습니다. 전국 지도가 전국 관광지 데이터 제공을 뜻하지는 않습니다. [기존 장소·사진 출처](docs/place-sources.md)와 [추가 장소·좌표 근거](docs/seongnam-tourism-expansion-sources.md)에 상세 범위를 기록했습니다.

## 사진과 이미지 편집

등록된 실제 사진이 있는 장소는 이를 기본 카드 이미지로 사용합니다. 신규 44곳은 등록 사진이 없어 장소 이름과 공식 근거를 담은 글 중심 카드로 생성합니다. 사진이 있는 카드는 장별 초점과 확대 비율을 조정하거나 기본 사진 복원, 권한을 확인한 사진 업로드, 선택한 카드의 AI 이미지 생성·재생성을 할 수 있습니다. 업로드는 PNG·JPEG·WebP, 최대 8MB·2천만 픽셀이며 서버에서 디코딩·재인코딩해 로컬에 저장합니다.

사진 변경은 해당 카드만 바꾸고 문구와 다른 카드를 유지합니다. 새 콘텐츠 버전이 만들어지므로 이전 검수·승인·출력 연결은 무효화되고 다시 검수해야 합니다. 모델이 문구를 수정해도 선택한 사진과 크롭은 보존합니다. 브라우저 미리보기와 1080×1080 PNG에 같은 크롭 값을 적용하고, 이미지 종류와 출처를 표시합니다.

AI 이미지 요청은 장소·주제·구도·조명·색감·질감·참조 사진·문구 여백·상상 여부를 구조화합니다. 참조 사진이 있으면 실제 바이트를 편집 API에 전달합니다. 생성된 이미지에는 AI 생성 표시를 붙이며 실제 장소나 확정 사업의 증거로 취급하지 않습니다. 한글 문구는 이미지와 별도로 합성합니다.

사진의 이용 조건은 자산별로 다릅니다. 참조 이미지의 원출처·저작자·라이선스와 생성 이력을 보존해야 하며, CC BY-SA 사진의 파생 이미지 배포에는 해당 동일조건변경허락이 적용됩니다. 상세 근거는 [사진 귀속정보](docs/place-sources.md#사진-귀속정보)를 따릅니다. AI 생성 표시는 원사진의 이용 조건을 없애지 않습니다.

| 기능 | 실행 방식 | 해석 |
| --- | --- | --- |
| 데모 `fixture` | 장소별 공식 발췌와 준비된 문구·오류 시나리오, 결정적 도구 선택 | 상태 전이·검수·편집·실제 파일 출력 확인 |
| 실제 AI `live` | 선택한 장소의 공식 본문 수집, Anthropic 판단·작성·독립 원자 검수 | 텍스트 모델 설정 필요 |
| AI 이미지 | OpenAI 이미지 API에 선택 카드의 시각 지시와 참조 사진 전달 | 텍스트 모드와 별도의 이미지 설정 필요 |
| 공식 자료 probe | 실제 공식 사이트 수집만 수행 | 모델 생성·의미 판단과 구분 |

fixture는 자유 입력을 이해해 새 문구를 만드는 기능이 아닙니다. 판교박물관의 역사적 연결 오류 시나리오도 준비된 회귀 사례이며 실제 모델의 판단 성능을 증명하지 않습니다. 실제 호출 실패를 데모 응답으로 자동 대체하지 않습니다.

공식 수집은 **선택한 장소에 등록된 읽기 전용 URL**로 제한합니다. 판교박물관은 기존 FAQ·건립배경과 허용된 관련 페이지를 사용하고, 다른 장소는 카탈로그에 등록된 공식 페이지 범위에서 수집합니다. 검색 한 번에 최대 8페이지·깊이 2·12초, 응답 2MB·신규 인용 32개를 허용합니다. 일반 웹 검색이나 임의 관광지 자동 확장은 제공하지 않습니다. 수집 인용은 검수 후보이며 주장 전체를 지지하는지 별도로 확인합니다.

## 지도 설정

`.env.local`에 `NCP_MAPS_CLIENT_ID`를 설정하고 NAVER Cloud Maps 애플리케이션에서 Dynamic Map과 사용할 Web 서비스 URL을 등록합니다. 예: `http://127.0.0.1`(포트·경로 제외), `localhost`는 별도 등록입니다. 서버 재시작 후 공개 설정 API가 브라우저용 Client ID만 전달합니다. 서버 비밀키는 필요하지 않으며 클라이언트로 전달하지 않습니다.

키가 없거나 NAVER 연결에 실패하면 OpenStreetMap 공식 임베드로 자동 전환합니다. 기본 지도는 선택 장소 핀 하나를 표시하며, 내부 핀 클릭을 앱 상세에 연결하거나 내부 이동·확대를 저장하는 기능은 제공하지 않습니다. 장소 선택란·목록과 전국·성남 버튼은 앱 상태에 연결됩니다. 다시 불러오기·큰 지도 열기를 제공하고 공급자 출처 표시는 유지합니다. SDK 인증·네트워크·시간 초과를 구분하고 전환 시 세션을 종료하여 늦은 이벤트가 화면을 되돌리지 않게 합니다. 실제 OpenStreetMap 타일 표시를 확인했으며 NAVER 실제 키 연결은 미검증입니다. [공식 문서와 선택 근거](docs/map-sdk-reference.md)

## API 설정

```bash
cp .env.example .env.local
```

값을 설정한 뒤 서버를 재시작합니다. 키는 서버에서만 사용합니다.

| 환경변수 | 용도 |
| --- | --- |
| `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL` | 실제 텍스트 판단·작성·검수, 구조화 출력 지원 모델 |
| `ANTHROPIC_INPUT_USD_PER_MILLION`, `ANTHROPIC_OUTPUT_USD_PER_MILLION` | 선택한 모델의 입력·출력 단가 |
| `ANTHROPIC_WORKSPACE_ID` | 필요한 경우 워크스페이스 지정 |
| `OPENAI_API_KEY`, `OPENAI_IMAGE_MODEL` | AI 이미지 생성·참조 편집 |
| `IMAGE_MAX_COST_USD_PER_CALL` | 이미지 한 번의 보수적 USD 예약액 |
| `MAX_COST_USD` | 텍스트·이미지 호출을 합한 실행 비용 한도 |
| `TIMESTORY_IMAGE_DIR` | 업로드·생성 이미지 저장 위치, 기본 `data/images` |
| `EVAL_MAX_COST_USD` | 실제 모델 평가 전체의 디스크 원장 기준 한도 |
| `EVAL_CLAIM_MAX_COST_USD` | 선택: 주장 평가 한 건의 예약 상한 |

필수 설정이 없으면 해당 유료 기능을 차단하고 연결 안내를 표시합니다. 기본 사진·업로드·크롭·데모 제작은 이미지 API 키 없이 사용할 수 있습니다. 호출 전에 비용을 저장하고 실패·취소·사용량 미확인에도 예약 기록을 유지합니다. 이미지 비용은 실제 청구액이 아닌 설정 예약액이며 텍스트 비용도 입력한 단가에 따른 추정값입니다.

현재 키 없는 검증 범위에는 실제 텍스트 모델 생성·수정 및 실제 AI 이미지 품질이 포함되지 않습니다. 연결 코드와 모의 응답 검증, 공식 사이트 읽기, 로컬 사진 렌더링을 유료 API 실측과 구분합니다.

2026-09-15 AI 에이전트 화면·쉬운 설명·문장 근거 보완은 단위·통합 테스트 332개(25개 파일), production E2E 32개, 타입 검사·ESLint·빌드를 통과했습니다. production E2E는 별도 로컬 포트 `43187`, `.next-e2e/`, `data/e2e.sqlite`를 사용합니다. 지도 탐색·장소 변경·기록 재진입·사진 편집·재검수·승인·ZIP과 1440/1024/390 화면 및 실제 PNG를 확인합니다. 자동화는 NAVER SDK 모의 구현을 사용합니다. 실제 인증·타일·모바일 제스처 검증과 구분합니다.

실제 모델 설정과 평가 예산이 갖춰지면 별도로 실행합니다.


기존 합성 주장과 고정 자료의 비교 평가는 관광지 전체·이미지 품질 평가가 아닙니다. fixture 결과만으로 AI 정확도나 작업 시간 절감, 에이전트의 우위를 주장하지 않습니다.
