# 성남 타임스토리 — 관광 탐색과 카드뉴스 제작

성남의 관광지를 지도에서 찾고, 공식 근거와 실제 장소 사진으로 한국어 카드뉴스 4장을 만드는 로컬 웹 앱입니다. 마지막 장은 상상으로 표시하며, 문구·사진 편집 후 재검수와 담당자 승인을 거쳐 PNG·ZIP을 내려받습니다.

[구현 명세](docs/implementation-spec.md) · [판단·검수 규칙](docs/agent-rules.md) · [장소·사진 출처](docs/place-sources.md) · [디자인 참조](docs/design-references.md) · [평가](docs/evaluation.md) · [3분 시연](docs/demo.md) · [개발 재개 프롬프트](docs/prompts/development.md)

현재 범위는 [관광 플랫폼 설계](docs/superpowers/specs/2026-09-13-tourism-platform-design.md)와 [구현 계획](docs/superpowers/plans/2026-09-13-tourism-platform.md)을 따릅니다. 초기 판교박물관 기획과 평가 사례는 이력으로 유지합니다.

## 실행

Node.js **24 이상**과 Chromium이 필요합니다. Node 내장 SQLite를 사용하며 실행 환경에 따라 experimental 경고가 표시될 수 있습니다.

```bash
npm ci
npx playwright install chromium
npm run dev
```

[http://127.0.0.1:3000](http://127.0.0.1:3000)에서 **관광지 탐색 → 장소 선택 → 이 장소로 카드뉴스 만들기**로 이동합니다. 데모 모드는 API 키 없이 사진이 포함된 카드와 파일을 제작합니다. 지도 타일은 온라인 연결이 필요하며, 로딩 실패 시에도 장소 목록을 사용할 수 있습니다.

최적화한 로컬 실행은 다음과 같습니다.

```bash
npm run build
npm start
```

개발·실행 서버는 `127.0.0.1`에 바인딩합니다. 로그인, 외부 공개 배포, SNS 자동 게시를 구현하거나 수행한 것은 아닙니다.

## 화면과 제작 흐름

- **대시보드**: 저장된 실행에서 집계한 제작·검토·승인 상태와 최근 작업을 표시합니다.
- **관광지 탐색**: 실제 OpenStreetMap 지도에서 전국 보기·성남 확대·이동·확대/축소와 마커 선택을 제공합니다. 검색·구·유형 필터를 장소 목록과 지도에 함께 적용합니다.
- **장소 상세**: 실제 사진, 주소, 공식 자료, 확인일, 운영정보와 사진 이용 조건을 확인합니다. 미확인·상충 정보는 확인 필요로 남깁니다.
- **카드뉴스 작업실**: 선택한 장소의 근거 수집, 작성, 원자 주장 검수, 부분 수정, 사진 편집, 재검수, 승인, 다운로드를 이어갑니다.
- **제작 기록**: SQLite에 저장된 작업을 다시 엽니다. 사이드바 메뉴 이동으로 현재 작업을 이어갈 수 있습니다.

등록 장소는 판교박물관·율동공원·중앙공원·성남아트센터·모란민속5일장·성남시청·봉국사 대광명전·망경암의 **8곳**입니다. 전국 지도가 전국 관광지 데이터 제공을 뜻하지는 않습니다. 공식 좌표의 의미와 사진별 저작자·라이선스는 [장소 출처 문서](docs/place-sources.md)에 기록했습니다.

## 사진과 이미지 편집

장소의 실제 사진을 기본 카드 이미지로 사용합니다. 카드별 초점과 확대 비율을 조정하거나 기본 사진 복원, 권한을 확인한 사진 업로드, 선택한 카드의 AI 이미지 생성·재생성을 할 수 있습니다. 업로드는 PNG·JPEG·WebP, 최대 8MB·2천만 픽셀이며 서버에서 디코딩·재인코딩해 로컬에 저장합니다.

사진 변경은 해당 카드만 바꾸고 문구와 다른 카드를 유지합니다. 새 콘텐츠 버전이 만들어지므로 이전 검수·승인·출력 연결은 무효화되고 다시 검수해야 합니다. 모델이 문구를 수정해도 선택한 사진과 크롭은 보존합니다. 브라우저 미리보기와 1080×1080 PNG에 같은 크롭 값을 적용하고, 이미지 종류와 출처를 표시합니다.

AI 이미지 요청은 장소·주제·구도·조명·색감·질감·참조 사진·문구 여백·상상 여부를 구조화합니다. 참조 사진이 있으면 실제 바이트를 편집 API에 전달합니다. 생성된 이미지에는 AI 생성 표시를 붙이며 실제 장소나 확정 사업의 증거로 취급하지 않습니다. 한글 문구는 이미지와 별도로 합성합니다.

사진의 이용 조건은 자산별로 다릅니다. 참조 이미지의 원출처·저작자·라이선스와 생성 이력을 보존해야 하며, CC BY-SA 사진의 파생 이미지 배포에는 해당 동일조건변경허락이 적용됩니다. 상세 근거는 [사진 귀속정보](docs/place-sources.md#사진-귀속정보)를 따릅니다. AI 생성 표시는 원사진의 이용 조건을 없애지 않습니다.

## 데모와 실제 AI

| 기능 | 실행 방식 | 해석 |
| --- | --- | --- |
| 데모 `fixture` | 장소별 공식 발췌와 준비된 문구·오류 시나리오, 결정적 도구 선택 | 상태 전이·검수·편집·실제 파일 출력 확인 |
| 실제 AI `live` | 선택한 장소의 공식 본문 수집, Anthropic 판단·작성·독립 원자 검수 | 텍스트 모델 설정 필요 |
| AI 이미지 | OpenAI 이미지 API에 선택 카드의 시각 지시와 참조 사진 전달 | 텍스트 모드와 별도의 이미지 설정 필요 |
| 공식 자료 probe | 실제 공식 사이트 수집만 수행 | 모델 생성·의미 판단과 구분 |

fixture는 자유 입력을 이해해 새 문구를 만드는 기능이 아닙니다. 판교박물관의 역사적 연결 오류 시나리오도 준비된 회귀 사례이며 실제 모델의 판단 성능을 증명하지 않습니다. 실제 호출 실패를 데모 응답으로 자동 대체하지 않습니다.

공식 수집은 **선택한 장소에 등록된 읽기 전용 URL**로 제한합니다. 판교박물관은 기존 FAQ·건립배경과 허용된 관련 페이지를 사용하고, 다른 장소는 카탈로그에 등록된 공식 페이지 범위에서 수집합니다. 검색 한 번에 최대 8페이지·깊이 2·12초, 응답 2MB·신규 인용 32개를 허용합니다. 일반 웹 검색이나 임의 관광지 자동 확장은 제공하지 않습니다. 수집 인용은 검수 후보이며 주장 전체를 지지하는지 별도로 확인합니다.

## API 설정

```bash
cp .env.example .env.local
```

값을 설정한 뒤 서버를 재시작합니다. 키는 서버에서만 사용합니다.

| 환경변수 | 용도 |
| --- | --- |
| `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL` | 실제 텍스트 판단·작성·검수, 구조화 출력 지원 모델 |
| `ANTHROPIC_INPUT_USD_PER_MILLION`, `ANTHROPIC_OUTPUT_USD_PER_MILLION` | 선택한 모델의 입력·출력 단가 |
| `ANTHROPIC_WORKSPACE_ID` | 필요한 경우 워크스페이스 지정 |
| `OPENAI_API_KEY`, `OPENAI_IMAGE_MODEL` | AI 이미지 생성·참조 편집 |
| `IMAGE_MAX_COST_USD_PER_CALL` | 이미지 한 번의 보수적 USD 예약액 |
| `MAX_COST_USD` | 텍스트·이미지 호출을 합한 실행 비용 한도 |
| `TIMESTORY_IMAGE_DIR` | 업로드·생성 이미지 저장 위치, 기본 `data/images` |
| `EVAL_MAX_COST_USD` | 실제 모델 평가 전체의 디스크 원장 기준 한도 |
| `EVAL_CLAIM_MAX_COST_USD` | 선택: 주장 평가 한 건의 예약 상한 |

필수 설정이 없으면 해당 유료 기능을 차단하고 연결 안내를 표시합니다. 기본 사진·업로드·크롭·데모 제작은 이미지 API 키 없이 사용할 수 있습니다. 호출 전에 비용을 저장하고 실패·취소·사용량 미확인에도 예약 기록을 유지합니다. 이미지 비용은 실제 청구액이 아닌 설정 예약액이며 텍스트 비용도 입력한 단가에 따른 추정값입니다.

현재 키 없는 검증 범위에는 실제 텍스트 모델 생성·수정 및 실제 AI 이미지 품질이 포함되지 않습니다. 연결 코드와 모의 응답 검증, 공식 사이트 읽기, 로컬 사진 렌더링을 유료 API 실측과 구분합니다.

## 검증과 재현

2026-09-13 관광 플랫폼 변경은 단위·통합 테스트 213개, production E2E 8개, 타입 검사·ESLint·빌드를 통과했습니다. 상세 결과와 직접 확인한 화면·PNG는 [평가 기록](docs/evaluation.md)에 기록했습니다. 아래 명령의 실행 결과를 기준으로 보고하며, 과거 판교박물관 테스트 수치를 이번 변경의 완료 근거로 사용하지 않습니다.

```bash
npm test
npm run typecheck
npm run lint
npm run build
npm run test:e2e
npm run eval
npm run eval:claims -- --validate
npm run sources:probe -- 판교박물관 관람료
```

production E2E는 별도 로컬 포트 `43187`, `.next-e2e/`, `data/e2e.sqlite`를 사용합니다. 지도 탐색·장소 변경·기록 재진입·사진 편집·재검수·승인·ZIP과 1440/1024/390 화면 및 실제 PNG를 확인합니다. 자동화의 지도 타일은 모의 응답으로 처리해 OSM 타일 서비스를 반복 수집하지 않습니다.

실제 모델 설정과 평가 예산이 갖춰지면 별도로 실행합니다.

```bash
npm run eval:smoke
npm run eval:claims -- --dev
npm run eval:claims -- --holdout
npm run eval:live
```

기존 합성 주장과 고정 자료의 비교 평가는 관광지 전체·이미지 품질 평가가 아닙니다. fixture 결과만으로 AI 정확도나 작업 시간 절감, 에이전트의 우위를 주장하지 않습니다.

## 저장과 개발

```text
src/app/          # 플랫폼 화면과 로컬 API
src/components/   # 지도·탐색·대시보드·이미지 편집·검수 화면
src/lib/          # 장소, 에이전트, 검수, 호출, 이미지, 저장, 렌더링
public/places/    # 실제 장소 사진과 attribution.json
scripts/          # fixture/live 평가와 공식 자료 probe
tests/            # 단위·통합·브라우저 테스트
docs/             # 명세, 출처, 설계 참조, 평가, 시연
data/             # 로컬 SQLite·이미지 저장소 (Git 제외)
outputs/          # 실행 버전별 PNG·대본·JSON·ZIP·평가 결과 (Git 제외)
```

Next.js·TypeScript·Node 내장 SQLite·Playwright와 로컬 Noto Sans KR를 사용합니다. [개발 재개 프롬프트](docs/prompts/development.md)는 승인된 개발 범위와 검증 절차를 이어가기 위한 문서입니다. 실제 모델 역할 지시는 [src/lib/prompts.ts](src/lib/prompts.ts), 이미지 지시는 [src/lib/image-provider.ts](src/lib/image-provider.ts)에 있습니다.

[GitHub 저장소](https://github.com/LSB-afk/-2026-2nd-Seongnam-KAIST-AI-Competition) · `seongnam-kaist.code-workspace`

비밀값과 `data/`, `outputs/`, `submissions/`, `.omx/`의 로컬 결과물을 커밋하지 않습니다. 커밋은 변경 이유와 필요한 검증·제약을 Lore 트레일러로 기록합니다.
